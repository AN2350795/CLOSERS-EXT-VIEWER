문제 확인 및 분류 안내 
세부 분류는 파일명 규칙으로 추정합니다. 기타 파일도 추출 대상입니다. HEADER 인덱스는 본문이 없어 일반 추출과 구분합니다. 미리보기 실패는 저장 실패와 별개입니다.

    
미지원 데이터 보존 · 인덱스 내보내기
저장 바이트 보존은 압축 해제나 복호화를 하지 않습니다. TET는 .TET 확장자를 유지하고, 나머지는 .stored.bin으로 별도 보존합니다. 확장자와 관계없이 원문은 미복원 상태입니다. 스크립트·오류 필터로 범위를 좁힌 뒤 실행하세요.
인덱스 내보내기는 위 원본 경로의 HEADER.CMF를 사용합니다. 새 하위 폴더에 목록만 저장하며 실제 리소스 본문은 DAT*.CMF에 있습니다.

데이터 관리 · 전체 초기화

    
분석 목록, 추출 파일, 오류·버전 이력, 그룹 이름·태그, 미리보기·이미지 조합 캐시와 보고서를 삭제합니다. 삭제한 데이터는 되돌릴 수 없습니다.

    
원본 CMF 파일과 원본 폴더는 유지합니다. 별도 출력 폴더에서는 목록과 버전 이력에 기록된 추출 파일만 삭제합니다.

    
    
보존 데이터는 원본 CMF 위치가 아니라, 별도로 복사한 .TET·.stored.bin 파일과 보존 기록입니다. 선택하지 않으면 보존 파일과 연결을 유지합니다. 별도 진단 폴더·HEADER 인덱스·브라우저로 내려받은 파일은 초기화 대상에 포함하지 않습니다.
