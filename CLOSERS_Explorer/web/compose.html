선택 레이어

원본 자르기 영역

게임 데이터와 저장 안내

에셋 선택에서 일러스트를 추가한 뒤 프레임·마크 탭의 썸네일을 눌러 적용하세요. 프레임과 마크는 각각 다른 항목으로 교체할 수 있습니다. 게임의 TOP·BOT 영역을 잘라 일러스트 테두리에 배치하며 마크 위치는 직접 조정합니다. 게임 정의 복원에는 원본 CMF, CW.EXE와 pycryptodome이 필요합니다. 썸네일과 DDS/TGA 변환에는 Pillow가 필요합니다.

프레임·마크를 선택하면 텍스처 애니메이션과 입자 생성·색상·크기·이동·회전·빛 번짐 효과를 자동 재생합니다. 효과 재생 버튼으로 멈추거나 시간 입력으로 원하는 시점을 볼 수 있습니다. 별도 마크 효과는 마크 중심에 연결되어 위치·크기·불투명도 변경을 따라갑니다. 같은 조합 설정은 같은 입자 배치를 재생하며, 게임에서 매번 달라지는 무작위 배치와는 차이가 있습니다. 파티클 표시에는 WebGL이 필요합니다.

현재 시점 PNG와 반복 APNG, 애니메이션을 포함한 조합 JSON을 PC로 저장합니다. APNG는 최대 250프레임·합계 268,435,456픽셀·128 MiB입니다. 출력은 게임 로딩 UI의 일러스트 크기로 고정되며, 입력은 한 이미지 16,777,216픽셀·64 MiB, 동시에 불러온 원본은 합계 134,217,728픽셀·256개, 레이어는 20개까지입니다. 원본 파일은 유지하며 복원 시 출처와 해시를 확인합니다.
