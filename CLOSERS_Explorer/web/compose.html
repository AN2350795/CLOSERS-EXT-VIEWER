선택 레이어

원본 자르기 영역

조합 저장과 원본 해상도 안내

PNG와 조합 JSON은 브라우저에서 PC로 내려받습니다. 여러 프레임 조각은 레이어로 배치해 템플릿으로 저장하고 다른 조합에 추가하세요. 원본 파일은 그대로 유지되며 합성 입력은 축소 미리보기와 분리합니다. DDS/TGA는 Pillow로 원본 해상도에서 변환합니다. 인게임 배치를 자동으로 재현하는 기능은 아닙니다.

출력은 한 변 8192px·총 16,777,216픽셀, 입력은 한 이미지 16,777,216픽셀·64 MiB, 동시에 불러온 원본은 합계 33,554,432픽셀, 레이어는 20개까지입니다. 설정 복원 시 원본 출처와 해시를 확인하며, 원본이 변경되거나 사라졌다면 오류를 표시하고 현재 조합을 유지합니다.
