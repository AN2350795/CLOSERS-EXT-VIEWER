    사용 방법과 상세 정보

    일러스트와 프레임 탭에서 썸네일을 선택하세요. 추가 장식에서 별도 마크를 추가할 수 있으며 위치는 직접 조정합니다. 애니메이션 효과는 자동 재생되고, 재생을 멈추거나 시점을 지정해 정지 이미지를 저장할 수 있습니다.

    구성 요소를 펼쳐 조각을 선택하면 세부 편집이 열립니다. 잠금을 해제한 뒤 드래그로 이동하고 오른쪽 아래 손잡이로 크기를 조절합니다. 방향키는 배치 기준 1px, Shift와 함께 누르면 10px 이동합니다. 체크 무늬와 선택 테두리는 저장되지 않습니다.

    PNG·무손실 WebP/APNG는 선택한 저장 해상도에서 원본을 직접 합성합니다. 미리보기 크기는 저장 해상도와 별개입니다. 조합 관리에서 설정을 저장·복원하거나 프레임 템플릿을 재사용할 수 있습니다.

    원본 데이터와 제한

    게임 정의 복원에는 원본 CMF·CW.EXE·pycryptodome, 썸네일과 DDS/TGA 변환 및 WebP 저장에는 Pillow가 필요합니다. 입자 효과에는 WebGL이 필요하며 고정 난수 시드로 재생하므로 실제 게임의 무작위 배치와는 차이가 있습니다.

    애니메이션은 최대 250프레임·128 MiB, 입력 이미지는 16,777,216픽셀·64 MiB, 불러온 원본 합계는 134,217,728픽셀·256개, 레이어는 20개까지입니다. 원본 파일은 유지하며 복원 시 출처와 해시를 확인합니다.
