# EXT B 채널의 활성 설정 조사

2026-10-31. 기존 조사에서 미확정이던 EXT B 계수의 **지역 배경 오브젝트 입력 경로**를 확인했다. 확인한 입력은 코스튬·아바타의 활성 조건을 확정하지 않는다. B 채널의 아바타 렌더링은 계속 보류한다.

## 확인한 원본 경로

CW.EXE SHA-256 `8ea0ce3ba885f3044103c8e071e627b52a0e93cf56cc44b0e03dffed7c440283`에 한정한 근거다.

| 단계 | 확인한 값 |
| --- | --- |
| 원본 목록 | `WORLD_TEMPLET.m_vecWorldObjData`의 개별 배경 오브젝트 |
| 활성화 | `m_bUseExt` → 템플릿 +0x1e9 |
| 계수 | `m_fUseExtIntensity` → 템플릿 +0x1ec |
| 기본값 | 활성화 false, 계수 1 — 두 값은 독립적 |
| 런타임 배치 | 오브젝트 +0x1c8에 템플릿을 포함하므로 각각 +0x3b1/+0x3b4 |
| 출력 | 활성 플래그가 1인 경우 `0x142f9ab00`의 `CBPerMaterial[18].x`에 계수 전달 |

`0x141677ef7`의 목록 진입과 `0x141677f43`의 로더 호출, `0x141683868~0x14168388f`의 두 필드 읽기를 확인했다. 템플릿 생성자 `0x1416774c5`는 +0x1e8에 16비트 값 1을 써서 +0x1e9를 0으로 만들며, `0x1416774ce`는 +0x1ec를 1로 초기화한다. `0x141683f7d`는 런타임 오브젝트 +0x1c8에 그 템플릿 생성자를 호출한다.

업로드의 두 경로 `0x14167c106~0x14167c117`, `0x14167e493~0x14167e4a4`는 활성화 +0x3b1을 검사한 뒤 계수 +0x3b4를 읽는다. `0x14167e305~0x14167e31a`는 활성 플래그를 렌더러 +0x160 상태에 전달한다. 이는 기존 PS에서 확인한 `surface * EXT.b * CBPerMaterial[18].x`의 계수 경로다. B는 파란색을 더하는 항이 아니라 기존 표면색에 곱하는 스칼라 입력이다.

## 실제 지역 입력과 아바타의 구분

평화의 광장 황혼의 배경 오브젝트 25개 중 3개가 `m_bUseExt=TRUE`다. 몽마르트르 황혼은 29개 모두 활성값을 생략해 원본 생성자 기준 false다. 두 지역의 54개 모두 계수 항목을 생략하여 원본 생성자 기준 1을 사용한다. 보고서는 생략값과 명시값 0/false를 구분하고, 기본값의 출처를 `source-constructor`로 표시한다.

같은 모델 이름이 여러 배경 인스턴스에서 쓰여도 인스턴스별 설정을 합치지 않는다. 잘못된 플래그나 계수를 0/1로 대체하지 않는다. 원본 필드와 배경 설정이 확인되었다는 이유로 아바타에 활성값이나 계수 1을 넣지 않는다. 아바타 EXT에 B 값이 있는 맵 3종도 이 배경 설정에 자동 연결하지 않는다. 아바타 렌더 경로에서 +0x160 활성 상태와 재질 상수를 설정하는 별도 근거가 필요하다.

```powershell
python -m unittest discover -s tests -p test_ext_binding.py -v
```

`--source`로 정확한 지역 Lua 파일명을 반복 지정할 수 있다. 실행 파일 지문과 바이트 근거 9곳이 맞는 경우에만 지역 입력을 조사한다. 게임과 Lua를 실행하지 않으며 원본 파일을 수정하지 않는다. 보고서에는 지역 원본 SHA-256, 아카이브·ordinal, 개별 오브젝트 경로, 활성값·계수의 명시 여부를 남긴다. `avatar_binding=unresolved`, `rendering_enabled=false`를 명시한다.

새 검사 9개는 기본값과 명시값의 구분, 활성화/계수 독립성, 0과 음수 보존, 잘못된 값 보류, 같은 모델의 별도 인스턴스, 구조 누락·실행형 Lua 거부, 다른 실행 파일 거부, 실제 실행 파일 근거와 지역 54개 입력을 검사한다. 기존 EXT 채널 진단·지역 조명·EXT GPU·툰 회전 검사도 재검증한다. 아바타 B 항을 새로 구현하거나 인게임 화면 일치를 검증한 단계는 아니다.
