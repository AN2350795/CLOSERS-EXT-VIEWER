# 캐릭터 동작 탐색

기존 화면은 선택한 X 뼈 파일과 이름이 같은 XMD만 연결했다. 실제 캐릭터의 이동·공격·스킬·아바타 전용 동작은 `MOTION_<캐릭터>_*.XMD`에 나뉘어 있어 기본 목록만으로 확인할 수 없었다.

## 사용

3D 모델을 연 뒤 재생 조작부의 **모든 동작 탐색**을 누른다. 종류를 고르거나 파일명·동작명·보조 이름으로 검색하고 동작을 선택한 뒤 **재생**을 누른다. 파일을 바꾸면 기본 자세로 복원한 후 새 동작을 연결한다. 목록은 60개씩 표시하며 검색은 모든 파일의 모든 클립에 적용한다.

현재 의상에 관계없이 같은 캐릭터의 아바타·이모션 모션을 포함한다. `RARE_3` 같은 코드로 묶음을 찾을 수 있다. 공식 의상 이름이나 해당 모션의 착용·해금 조건은 확인되지 않았으므로 추정해서 연결하지 않는다. 스킬도 원본 동작명을 유지하며 이펙트·피격 대상·게임 로직은 포함하지 않는다.

| 종류 | 파일명 근거 |
|---|---|
| 기본 · 이동 | `MOTION_<캐릭터>.XMD` |
| 전투 · 피격 | `ATTACK`, `CASH_ATTACK`, `DAMAGE` |
| 스킬 | `SKILL`, `TASKFORCE` |
| 아바타 변형 | `COMMON`, `RARE`, `DEVIL`, `CASH` |
| 이모션 | `EMOTION` 포함, 아바타 코드보다 우선 |
| 로비 · 마을 | `LOBBY`, `TOWN` |
| 상호작용 | `INTERACT` |
| 기타 | 나머지 관련 파일 |

## 데이터와 검증

`GET /api/model-motion-library?skeleton=<X 항목 ID>&entries=<장착 X 항목 ID 목록>`은 현재 목록에서 캐릭터 접두어가 정확히 일치하는 모든 XMD와 장착 모델·뼈의 동명 XMD를 찾는다. 숫자 접두어가 붙은 공통 액세서리의 동명 XMD도 포함한다. NPC·몬스터처럼 캐릭터 모션 접두어가 없는 모델은 동명 파일을 탐색한다. 파일명 일부가 비슷한 다른 캐릭터의 파일은 섞지 않는다.

파일별 출처·항목 ID·클립 인덱스·원본 이름·보조 이름·길이를 유지한다. 동일 이름의 XMD도 출처별로 별도 표시한다. 검색 목록에는 키프레임 전체를 보내지 않고 선택 시 기존 클립 API로 불러온다. 첫 탐색 때 관련 파일의 내용을 읽고 기본 자세를 검증하며, 모델을 바꾸면 화면의 탐색 결과를 초기화한다. 원본 추출 파일과 Catalog 분류는 변경하지 않는다.

현재 뼈와 XMD의 뼈 수 및 `_DEFAULT`의 모든 로컬 행렬을 대조한다. 실패하면 동명 X 파일 후보, 캐릭터 기본 공용 뼈 순서로 별도로 검증하고 통과한 출처가 정확히 하나인 경우에만 뼈 전환을 제공한다. 특수 뼈를 사용하다 일반 모션을 선택하면 기본 공용 뼈로 돌아갈 수 있다. 후보가 없거나 중복되어 확정할 수 없으면 재생을 보류한다. 기본 자세가 다른 파일을 오차 허용치를 늘려 연결하지 않는다.

읽기 오류·형식 미지원·뼈 불일치 파일도 오류 사유와 함께 목록에 남긴다. 클립 목록까지 읽은 경우 그 이름도 검색할 수 있다. `_DEFAULT`는 검증용이므로 처음에는 숨기며 체크박스로 포함할 수 있다. 파일별 기존 입력·키프레임 제한은 유지한다. 미추출 항목은 원본 CMF에서 읽고, 원본이 없어도 저장된 파일이 있으면 탐색할 수 있다.

## 확인

`test_model_motions.py`는 별도 묶음 발견, 다른 캐릭터 제외, 중복 출처, 오프라인 저장 파일, 손상 파일, 기본 자세 불일치, 전용 뼈 및 중복 전용 뼈를 검증한다. `test_motion_library_browser.py`는 전체 검색·종류 필터·페이지 이동·검증 자세 표시·정확한 출처 선택·전용 뼈 전환·이전 모델 응답 무시를 Chromium에서 확인한다.
