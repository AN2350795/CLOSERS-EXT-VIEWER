# 뷰어 조명과 확장 지점

## 사용

모델 뷰어의 **조명 · 재질 → 기본 꾸미기 → 뷰어 조명**에서 사용한다. 기본은 꺼짐이며, 아래 세부 설정에서 종류·위치·조준점·빛 색상·강도·주변 밝기를 조절한다. 좌표는 변환이 끝난 뷰어 월드 기준으로 Y가 위쪽이다. 카메라 이동과 독립적으로 고정되며 원본 게임 좌표의 Z 반전은 직접 적용하지 않는다.

| 종류 | 좌표와 전용 설정 |
| --- | --- |
| 방향광 | 위치에서 조준점을 향하는 평행한 빛. 거리 감쇠 없음 |
| 점광원 | XYZ 위치와 도달 거리. 거리에 따른 제곱 감쇠 |
| 스포트라이트 | XYZ 위치·조준점·도달 거리·반각(1~89도), 경계 부드러움 |
| 환경광 | 방향에 관계없이 지정한 색상·강도 적용 |

주변 밝기는 모든 종류에 더하는 중성 밝기다. 방향광의 위치와 조준점이 같으면 직접광 기여는 0이다. 점광원·스포트라이트의 도달 거리는 뷰어 단위다. 투영 그림자나 광원 도형은 생성하지 않는다. 한 개의 수동 광원을 지원한다.

켜짐·종류·수치를 `closers-viewer-light-v1`에 별도로 저장한다. 모델을 바꾸거나 다시 열어도 유지하며 모델이 없을 때도 편집할 수 있다. 비어 있거나 범위 밖인 숫자는 마지막 유효값으로 돌린다. 초기화는 뷰어 조명만 기본값·꺼짐으로 되돌린다. 원본 조명 프로필과 착용 조건 설정은 별도로 유지한다.

## 현재 구현 범위

아래는 코드에서 확인한 기능 범위다. 전체 인게임 조명 재현 완료를 의미하지 않는다.

| 영역 | 현재 구현 | 남은 연결·검증 |
| --- | --- | --- |
| 원본 조명 데이터 | 의상·지역 프로필, 출처 표시, 착용 조건 후보, 수동 스킨 선택, 조건 기반 자동 선택 | 게임의 실제 스킨 선택·콘텐츠 활성 상태·효과 우선순위 |
| 표면 음영 | 툰 램프, 얼굴 SDF, GLOW, EXT 반사와 B 채널 가산, 테두리광, MatCap·반사 비교 | 근사 경로의 실제 게임 화면 대조, 전체 의상·장면 검증 |
| 조명 합성 | 지역·스킨 합성, 원거리/근거리 강도, 수동 회전, 뷰어 카메라 거리 보정 | 실제 게임의 거리 기준·회전·장면 렌더 상태 |
| 화면 효과 | 발광, 번짐, 원본 형식 색상 계산, 색상 보정, 선명도, 심도 | 게임 장면·전체 후처리 체인과 일치 검증, 미지원 효과 경로 |
| 뷰어 직접 조명 | 이번에 추가한 네 종류와 공통 수치 | 복수 광원·그림자·광원 표시 등은 향후 별도 구현 |

관련 상세 문서는 `AVATAR_LIGHT_CONDITIONS.md`, `AVATAR_LIGHT_COMPOSITION.md`, `AVATAR_CAMERA_LIGHT.md`, `AVATAR_TOON_ROTATION.md`, `AVATAR_LIGHTING_MENU.md`에 있다. 춤 스포트라이트·음표는 선택형 연출 텍스처/모델이며 이 수동 표면 조명과 별개다.

## 확장

`web/model-viewer-light.js`는 원본 프로필 읽기와 독립된 상태 정규화·종류 정의·셰이더 적용·메뉴 생성을 제공한다. `viewerLightTypes`의 안정적인 ID와 `fields`에 종류 및 표시할 항목을 등록하고 해당 셰이더 분기를 추가한다. 공통 수치는 기본값·범위·uniform·컨트롤에 추가한다. 기존 ID를 재사용하지 않고 저장 형식 변경 시 버전을 갱신한다. 향후 복수 광원은 상태 배열과 uniform 배열/루프로 확장해야 한다.

기본 재질이 `MeshBasicMaterial`이므로 Three의 Light 객체만 추가해도 아바타는 반응하지 않는다. `setViewerLight()`가 기존 재질의 컴파일 훅과 캐시 키를 이어받고, `model-lighting.js`의 `viewer_light_surface` 지점에 표면 조명을 삽입한다. 스키닝 이후 월드 위치와 기존 월드 법선을 사용한다. 원본 툰·얼굴·보조광 처리 전에 표면에 적용하므로 이후 추가되는 발광을 어둡게 만들지 않는다. 광택 마스크 검사와 발광 전용 패스는 기존 출력이 우선한다. 끄면 표면 계산을 건너뛴다. 모델 변경 시 `refresh()`가 새 재질에 설정을 적용하며 프레임마다 셰이더를 다시 만들지 않는다.

새 JS 모듈은 `closers/server.py`의 정적 파일 허용 목록에도 등록해야 한다. 브라우저 검사 `test_viewer_light_browser.py`는 실제 WebGL 픽셀로 각 종류의 방향·감쇠·색상·OFF 복원·출력 알파·발광 전용 분리를 확인하고, 저장 복원·잘못된 입력·모델 교체를 검사한다. 실제 인게임 화면 대조는 이 검사에 포함되지 않는다.
