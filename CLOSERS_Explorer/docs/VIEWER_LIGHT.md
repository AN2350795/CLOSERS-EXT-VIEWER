# 뷰어 조명과 확장 지점

## 사용

모델 뷰어의 **조명 · 재질 → 기본 꾸미기 → 뷰어 조명**에서 사용한다. 기본은 꺼짐이며, 아래 세부 설정에서 종류·위치·조준점·빛 색상·강도·주변 밝기를 조절한다. 좌표는 변환이 끝난 뷰어 월드 기준으로 Y가 위쪽이다. 카메라 이동과 독립적으로 고정되며 원본 게임 좌표의 Z 반전은 직접 적용하지 않는다.

## 음영 방식

기본 **원본 툰·얼굴 음영**은 지정한 주광원 1개로 기존 원본 툰 텍스처와 얼굴 SDF의 방향·색·강도를 제어한다. 이전의 일반 입체 음영은 법선과 광원 방향의 내적을 표면에 곱하는 방식이어서, 툰 음영과 중복되면 입체감과 명암이 과장될 수 있었다. 원본 모드에서는 이 추가 음영을 완전히 끈다. 기존 저장값에 음영 방식이 없을 때도 원본 모드로 시작하며, 일반 방식은 직접 선택해 비교할 수 있다.

**음영을 제어할 주광원**에서 사용할 광원을 선택한다. 원본 툰·얼굴 연결이 준비된 부위에만 적용하며 미연결 부위는 기존 재질을 유지한다. 별도의 원본 조명을 선택하지 않아도 뷰어 주광원으로 연결된 음영을 사용할 수 있다. 선택한 원본 프로필이 있으면 그 색·강도에 주광원의 색·강도를 곱하고 반사·테두리광 수치를 이어받는다. 원본 툰·얼굴 켜짐 선택이나 저장한 프로필을 변경하지 않으며 뷰어 조명을 끄면 원래 선택으로 복원한다. 표면 보조광·반사·테두리광은 각 효과의 기존 켜짐 선택을 유지한다.

이 모드의 주광원은 방향광·점광원·스포트라이트를 지원한다. 점광원·스포트라이트의 방향과 거리 감쇠는 **모델 루트의 월드 원점**에서 계산해 원본 셰이더의 단일 방향 입력으로 전달한다. 물체의 각 픽셀에서 광원까지의 거리를 재는 방식이 아니다. 회전 비교보다 주광원의 직접 배치를 우선한다. 다른 뷰어 광원과 공통 주변 밝기는 음영에 더하지 않는다. 주광원이 아닌 표시선은 흐리게 표시하고, 3D 이동 도구 모음에 현재 음영 기준 광원을 표시한다. 환경광은 원본 주광원으로 사용할 수 없다. 주광원을 끄거나 방향이 정의되지 않으면 원래 음영을 유지한다.

**일반 입체 음영 · 비교용**은 기존의 최대 4개 광원 합산·공통 주변 밝기와 표면별 거리 감쇠를 유지한다. 인게임 외관을 목표로 할 때는 원본 모드를 사용한다. 어느 모드도 실제 게임의 전체 장면 조명·그림자·후처리와의 일치를 보장하지 않는다.

**3D 조절기로 이동**을 누르면 설정 창이 닫히고 선택한 광원에 XYZ 이동 조절기가 나타난다. **빨강 X·초록 Y·파랑 Z 화살표**를 드래그하면 해당 월드 축으로만 이동한다. 가운데 흰 사각형은 화면과 평행한 평면에서 자유롭게 이동한다. 카메라 방향과 거의 나란한 축은 드래그 방향을 구별하기 어려워 숨긴다. 이동 중에는 카메라 회전·이동·휠 확대를 막고, 핸들 밖에서는 기존 카메라 조작을 유지한다.

뷰어 안의 도구 모음에서 이동할 광원과 **광원 위치 / 조준점**을 선택한다. 조준점 이동은 방향광·스포트라이트에 제공하며 점광원은 위치만 이동한다. 환경광은 이동할 위치가 없다. 광원이 화면 밖에 있으면 **모델 옆으로**로 선택한 광원의 위치를 모델 근처에 배치한다. 조준점 모드의 같은 버튼은 조준점을 모델 중심에 놓는다. **이동 끝내기**는 조절기를 숨기며 조명 효과는 유지한다.

드래그 중 좌표·조명은 실시간으로 갱신하고 마우스나 손가락을 놓을 때 저장한다. **Esc** 또는 포인터 취소 시 드래그 시작 좌표로 되돌린다. 모델·광원·이동 대상을 바꾸거나 초기화·종료하는 경우에도 진행 중 이동을 취소한다. 조명 효과가 꺼져 있어도 배치를 편집할 수 있다. 기존 숫자 입력도 함께 사용할 수 있다. 조절기의 켜짐과 이동 대상은 v2 저장값의 `gizmoEnabled`·`gizmoTarget`으로 보관하며 기본은 꺼짐·광원 위치다.

| 종류 | 좌표와 전용 설정 |
| --- | --- |
| 방향광 | 위치에서 조준점을 향하는 평행한 빛. 거리 감쇠 없음 |
| 점광원 | XYZ 위치와 도달 거리. 거리에 따른 제곱 감쇠 |
| 스포트라이트 | XYZ 위치·조준점·도달 거리·반각(1~89도), 경계 부드러움 |
| 환경광 | 방향에 관계없이 지정한 색상·강도 적용 |

**조명 추가**로 최대 4개의 수동 광원을 배치한다. **편집할 조명**에서 항목을 고르고 이름·켜짐·종류·수치를 각각 수정한다. 새 조명은 켜진 점광원·강도 0.5로 추가하며 전체 켜짐 설정은 유지한다. **선택 조명 삭제**는 해당 항목만 제거하고 나머지 조명의 값을 유지한다. 최소 1개를 남기며, 마지막 조명은 개별 스위치로 끌 수 있다.

일반 입체 음영 모드에서는 켜진 광원의 색상별 기여를 더한 뒤 표면에 적용한다. **공통 주변 밝기**는 광원 수와 관계없이 한 번 더하는 중성 밝기다. 전체 스위치를 끄거나 모든 개별 조명을 끄면 기존 화면으로 복원한다. 강도가 0인 켜진 조명만 있으면 공통 주변 밝기만 적용한다. 점광원·스포트라이트의 도달 거리는 뷰어 단위다. 투영 그림자는 아직 지원하지 않는다.

**광원 위치·방향·범위 표시**를 켜면 방향광은 위치·조준점·화살표, 점광원은 도달 거리의 구 테두리, 스포트라이트는 방향·반각·거리 테두리를 표시한다. 선택한 광원 위치에는 흰 십자가 추가된다. 전체 또는 개별 조명이 꺼졌어도 위치를 편집할 수 있도록 흐리게 표시한다. 환경광은 위치가 없어 도형을 표시하지 않는다. 위치와 조준점이 같으면 방향 화살표와 스포트 범위를 생략한다.

표시는 기본 꺼짐이며 `showHelpers`로 기존 v2 저장값에 함께 보관한다. 모델이 없거나 발광 전용·광택 마스크 진단 화면에서는 숨긴다. 카메라 자동 맞춤에 포함하지 않으며, 물체에 가려지지 않는 편집용 선으로 후처리 완료 화면 위에 그린다. 따라서 번짐·심도·색상 보정의 대상이 아니다. 화면 캡처 시 표시가 필요 없으면 이 스위치를 끈다. 전체 초기화 시 표시도 꺼진다.

전체 켜짐·공통 주변 밝기·선택 항목·각 광원 설정을 `closers-viewer-light-v2`에 별도로 저장한다. 기존 `closers-viewer-light-v1` 단일 조명은 첫 광원으로 읽고 원래 켜짐을 전체 스위치에, 주변 밝기를 공통값에 옮긴다. 첫 광원의 개별 스위치는 켜짐으로 두어 전체 스위치를 다시 켰을 때 예전과 동일하게 동작한다. v2 저장값이 있으면 이를 우선하며 v1은 삭제하지 않는다.

음영 방식은 `mode`(`source`/`diffuse`), 주광원은 `sourceIndex`로 함께 저장한다. 전체 초기화는 원본 음영 모드·첫 번째 광원으로 되돌린다.

모델을 바꾸거나 다시 열어도 설정을 유지하며 모델이 없을 때도 편집할 수 있다. 비어 있거나 범위 밖인 숫자는 마지막 유효값으로 돌린다. **뷰어 조명 전체 초기화**는 광원 1개·전체 꺼짐·주변 밝기 0.3으로 되돌린다. 원본 조명 프로필과 착용 조건 설정은 별도로 유지한다.

## 현재 구현 범위

아래는 코드에서 확인한 기능 범위다. 전체 인게임 조명 재현 완료를 의미하지 않는다.

| 영역 | 현재 구현 | 남은 연결·검증 |
| --- | --- | --- |
| 원본 조명 데이터 | 의상·지역 프로필, 출처 표시, 착용 조건 후보, 수동 스킨 선택, 조건 기반 자동 선택 | 게임의 실제 스킨 선택·콘텐츠 활성 상태·효과 우선순위 |
| 표면 음영 | 툰 램프, 얼굴 SDF, GLOW, EXT 반사와 B 채널 가산, 테두리광, MatCap·반사 비교 | 근사 경로의 실제 게임 화면 대조, 전체 의상·장면 검증 |
| 조명 합성 | 지역·스킨 합성, 원거리/근거리 강도, 수동 회전, 뷰어 카메라 거리 보정 | 실제 게임의 거리 기준·회전·장면 렌더 상태 |
| 화면 효과 | 발광, 번짐, 원본 형식 색상 계산, 색상 보정, 선명도, 심도 | 게임 장면·전체 후처리 체인과 일치 검증, 미지원 효과 경로 |
| 뷰어 직접 조명 | 네 종류, 최대 4개 광원 합산, 개별 켜짐·추가·삭제·이름, 공통 주변 밝기, 위치·방향·범위 표시, XYZ 드래그 이동 | 투영 그림자, 회전·크기 전용 핸들 등은 향후 별도 구현 |

관련 상세 문서는 `AVATAR_LIGHT_CONDITIONS.md`, `AVATAR_LIGHT_COMPOSITION.md`, `AVATAR_CAMERA_LIGHT.md`, `AVATAR_TOON_ROTATION.md`, `AVATAR_LIGHTING_MENU.md`에 있다. 춤 스포트라이트·음표는 선택형 연출 텍스처/모델이며 이 수동 표면 조명과 별개다.

## 확장

`web/model-viewer-light.js`는 원본 프로필 읽기와 독립된 상태 정규화·종류 정의·셰이더 적용·메뉴 생성을 제공한다. `viewerLightTypes`의 안정적인 ID와 `fields`에 종류 및 표시할 항목을 등록하고 해당 셰이더 분기를 추가한다. 공통 수치는 기본값·범위·uniform·컨트롤에 추가한다. 기존 ID를 재사용하지 않고 저장 형식 변경 시 버전을 갱신한다.

`normalizeViewerLights()`가 전체 설정과 광원 배열을 검증한다. 광원 수 상한은 `maxViewerLights`로 통일하며 현재 4개다. GLSL은 고정 길이 `ViewerLight` struct uniform 배열을 순회하고 켜진 항목의 기여만 더한다. 공통 주변 밝기는 루프 밖에서 한 번만 더한다. 추가·삭제·편집은 uniform 값만 바꾸며 셰이더를 재컴파일하지 않는다. 삭제 후 남은 슬롯의 enabled를 0으로 갱신해 이전 광원이 남지 않게 한다.

기본 재질이 `MeshBasicMaterial`이므로 Three의 Light 객체만 추가해도 아바타는 반응하지 않는다. `setViewerLights()`가 기존 재질의 컴파일 훅과 캐시 키를 이어받고, 일반 모드에서만 `model-lighting.js`의 `viewer_light_surface` 지점의 추가 표면 조명을 켠다. 스키닝 이후 월드 위치와 기존 월드 법선을 사용한다. 원본 툰·얼굴·보조광 처리 전에 표면에 적용하므로 이후 추가되는 발광을 어둡게 만들지 않는다. 광택 마스크 검사와 발광 전용 패스는 기존 출력이 우선한다. 끄면 표면 계산을 건너뛴다. 모델 변경 시 `refresh()`가 새 재질에 설정을 적용하며 프레임마다 셰이더를 다시 만들지 않는다.

원본 모드는 `viewerSourceProfile()`이 주광원의 월드 방향을 원본 Z 반전 이전 좌표로 변환해 전달한다. `applyViewerSource()`가 기존 setAvatarToon/FaceSdf/Glow/Ext/Rim 경로를 사용하며 원본 설정을 저장하거나 수정하지 않는다. 카메라 거리 혼합이 갱신돼도 주광원 배치를 다시 적용한다. 3D 드래그 중에는 이 재질 갱신만 수행하고 전체 메뉴·착용 조건 목록은 다시 만들지 않는다.

`model-viewer-light-helpers.js`는 독립적인 overlay Scene을 관리한다. `model.js`가 후처리 렌더 후 `lighting.renderHelpers()`를 호출한다. 광원 설정이나 선택 항목이 달라질 때만 선 지오메트리를 교체하고 이전 geometry/material을 해제한다. 프레임마다 재생성하지 않으며 렌더러의 autoClear를 복원한다. 뷰어 종료 시 `lighting.dispose()`가 남은 자원을 해제한다. 스포트 경계는 셰이더의 구형 거리 감쇠 범위에 맞춰 광원에서 길이가 distance인 원뿔 가장자리로 계산한다.

`model-light-gizmo.js`는 월드 축과 카메라를 이용한 레이/평면 교차로 이동량을 구한다. 각 축이 포함된 드래그 평면을 사용하며 축 방향으로 이동량을 투영한다. 화면상의 크기를 약 85 CSS 픽셀로 유지한다. 캡처 단계에서 핸들 드래그 이벤트를 처리해 기존 orbit 핸들러와의 중복 조작을 막는다. 별도의 overlay Scene으로 후처리 완료 화면에 그리며 모델 범위·발광·심도에 포함하지 않는다. bindGizmo는 렌더러 초기화 시 카메라와 canvas를 연결하고 dispose는 포인터/키보드 이벤트와 geometry/material을 해제한다.

새 JS 모듈은 `closers/server.py`의 정적 파일 허용 목록에도 등록해야 한다. 브라우저 검사 `test_viewer_light_browser.py`는 실제 WebGL 픽셀로 각 종류의 방향·감쇠·색상·OFF 복원·출력 알파·발광 전용 분리를 확인하고, 저장 복원·잘못된 입력·모델 교체를 검사한다. `test_multi_viewer_light_browser.py`는 네 종류 동시 합산, 공통 밝기 중복 방지, 전체/개별 OFF, 추가·삭제·개수 제한, 재컴파일 방지와 단일 조명 저장값 이관을 검사한다. 실제 인게임 화면 대조는 이 검사에 포함되지 않는다.

`test_viewer_light_helpers_browser.py`는 범위 지오메트리, 선택·꺼짐 표시, 자원 해제, GPU 표시/OFF 복원, 발광 전용 분리와 모델 제거를 검사한다. `test_viewer_light_helpers_scene_browser.py`는 실제 model.js 렌더 루프에서 표시 변화·원본 프레임 복원·카메라 유지·모델 제거·종료 경로를 검사한다.

`test_light_gizmo_browser.py`는 실제 카메라/레이캐스트로 XYZ 축별 이동, 가운데 평면 이동, Esc·포인터 취소, 저장 시점을 검사한다. 실제 model.js 경로에서도 modal 닫기·도구 모음·광원/조준점 드래그·숫자 갱신·카메라 유지·진단 화면 숨김·모델 제거를 검사한다. 합성 포인터를 사용하므로 테스트에서만 캡처 API를 모형화한다.

`test_viewer_source_light_browser.py`는 일반·4·5가중치 모델에서 원본 툰·얼굴 SDF 경로와 GPU 픽셀을 비교한다. 추가 일반 음영 비활성, 미연결 부위 유지, 공통 밝기·보조 광원 미적용, 원본 프로필 계승·복원, 주광원 선택과 비교 모드 전환을 검사한다. 이는 원본 셰이더 경로 재사용 검사이며 실제 인게임 캡처와의 일치 검사는 아니다.
