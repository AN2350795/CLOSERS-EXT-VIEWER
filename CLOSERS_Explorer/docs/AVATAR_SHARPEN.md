# 원본 선명도 비교

2026-11-01. 원본 Edge 셰이더와 선명도 계수 전달 경로를 확인하고, 기본 OFF인 전체 화면 비교를 추가했다. **RGB는 확인한 원본 식을 사용하고, 투명 배경의 알파는 보존한다.** 게임의 실시간 후처리 상태·최종 화면 전체를 자동 재현하는 기능은 아니다.

## 사용법

아바타를 선택하고 조명 · 발광에서 **원본 형식의 색상 계산 비교**를 켠다. **원본 선명도 비교 · 알파 유지**를 펼쳐 주변 샘플 거리(0~5픽셀)를 지정하고 비교를 켠다. 기본은 꺼짐·거리 0이며 켜짐과 거리를 브라우저에 저장한다. 거리 0은 원래 화면을 그대로 통과시킨다.

원본 색상 프리셋을 선택한 뒤 **선택 프리셋의 선명도 수치만 가져오기**를 누르면 선명도 수치만 복사한다. 선명도 켜짐·색상 보정·빛 번짐 설정은 바꾸지 않는다. 확인되지 않은 선명도 값은 복사할 수 없다. 기존 **선택 프리셋 수치 적용** 버튼은 계속 색상 수치만 복사한다.

발광만 보기와 광택 마스크 확인 중에는 선명도를 보류한다. 원본 색상 계산을 끄거나 모델을 지워도 저장한 선택을 유지하되 적용은 중단한다. 초기화는 거리만 0으로 바꾸며 켜짐 선택은 유지한다. 조명·툰·하이퍼 모드 효과를 자동으로 켜지 않는다.

## 원본 셰이더와 계수 의미

원본 `CW_EDGE.PS.CSO`는 2,728바이트이며 SHA-256은 `acdb46d12080aa44274aeb21d3238a19c35dd109d885b8763d052be7a9cab5cc`이다. 카탈로그의 모든 동명 원본이 이 지문과 같을 때만 확인된 셰이더로 인정한다.

셰이더는 `CBPerPostProcess[30].x`를 렌더 타깃의 너비·높이로 나눠 UV 오프셋을 만든다. 가운데 샘플을 C, 지정 거리의 8방향 샘플을 N이라 하면 식은 다음과 같다.

```
output = 2*C - sum(N[0:8])/8
```

따라서 수치는 고정된 커널의 증폭 배율이 아니라 **샘플 거리**다. 소수 거리도 그대로 사용한다. 뷰어에서는 실제 그리기 버퍼 픽셀 크기를 기준으로 계산하고, 화면 가장자리는 Clamp와 선형 보간으로 읽는다. 게임 샘플러의 모든 런타임 상태와 화면 크기별 최종 외형 일치는 미검증이다.

원본은 RGBA 모두를 위 식으로 출력한다. 뷰어는 배경 분리·투명 내보내기를 위해 원래 alpha를 유지한다. 알파 처리까지 원본과 동일하다고 주장하지 않는다.

## CPU 연결과 순서

CW.EXE SHA-256 `8ea0ce3ba885f3044103c8e071e627b52a0e93cf56cc44b0e03dffed7c440283`에서 다음을 확인했다.

| 위치 | 연결 |
| --- | --- |
| `0x1406d4f39~0x1406d4f74` | SHARPEN 활성값 → 후처리 bit 6, 수치 → 런타임 +0x318 |
| `0x141674c62~0x141674c82` | bit 6일 때 +0x318 → `0x142fb67f0`, CBPerPostProcess+480 |
| `0x141572394` | 선명도 패스가 기법 10 선택 |
| `0x141606b42` | 열 번째 PS로 `CW_Edge.PS.cso` 등록 |
| `0x141575ff0~0x141576158` | Glow 합성 → Edge → 나머지 조건부 패스 → ColorGrading |
| `0x1415743b1`, `0x141575354~0x141575364` | 포맷 28의 타깃 정의로 선명도 중간 타깃 +0x310 생성 |

뷰어는 기존 발광·번짐 합성을 먼저 완료한 뒤 UNORM8 중간 이미지에 선명도를 적용하고 색상 보정을 마지막에 수행한다. 선명도 출력도 UNORM8로 기록하여 범위 제한과 양자화가 색상 보정보다 먼저 일어난다. 게임의 다른 조건부 패스까지 구현한 것은 아니다. 선명도가 OFF 또는 거리 0일 때는 추가 패스를 사용하지 않는다.
