# 로딩 카드 하단 정보

조합 화면의 **캐릭터 정보 → 이미지에 하단 정보 포함**으로 표시합니다. 기본값은 사용 안 함입니다. 레벨 표기, 캐릭터명·직함, 닉네임, 진행률은 각각 자유롭게 입력하거나 비울 수 있습니다. 문구가 길면 지정 영역에서 잘라 표시하며 글자 크기를 줄이지 않습니다. 진행률이 `31%` 또는 `31` 같은 수치이면 하단 게이지를 해당 비율로 표시합니다. 그 밖의 문구나 빈 값에서는 게이지를 표시하지 않습니다.

정보를 켜면 기존 일러스트 영역 450×640 아래에 80px을 추가해 450×720으로 출력합니다. 일러스트와 프레임의 위치·크기는 유지합니다. 원본 해상도·2배·사용자 지정 출력에서는 정보 영역도 같은 배율로 확대합니다. 표시를 껐다 켜면 입력과 엠블럼 선택을 유지하고, 조합 초기화 시 함께 초기화합니다.

## 데이터 출처

`DLG_LOADING_DUNGEON_START_V2.LUA`의 `SLOT_1_INFO`, `SLOT_1_IMG`, `SLOT_1_AGENT_GRADE`와 `FONT_MANAGER.LUA`, `PARTICLE_SYSTEM_UI*.LUA`, `TEX_ANIM_DATA.LUA`를 읽습니다. 원본 일러스트 좌상단을 (0, 0)으로 환산한 설정은 다음과 같습니다.

| 항목 | 위치 | 글꼴 | 크기 | 색상·정렬 |
| --- | --- | --- | --- | --- |
| 레벨 표기 | 92, 672 | NanumGothicExtraBold.ttf | 13px | 흰색·왼쪽 |
| 캐릭터명·직함 | 140, 672 | NanumGothicExtraBold.ttf | 13px | 흰색·왼쪽 |
| 닉네임 | 92, 692 | NanumGothicExtraBold.ttf | 13px | RGB 255, 204, 0·왼쪽 |
| 진행률 | 442, 682 | NanumGothicBold.ttf | 24px | 흰색·오른쪽 |

텍스트의 세로 기준은 중앙입니다. 외곽선 크기와 색상 계수도 글꼴 정의에서 읽습니다. 게임 설치 폴더의 실제 TTF를 로드하며, 글꼴이 없거나 저장된 SHA-256과 다르면 대체 글꼴로 저장하지 않고 오류를 표시합니다. 브라우저와 게임 FreeType의 글리프 래스터화는 다를 수 있으며, 게임 전용 `m_fBoldRate`의 보정 연산은 재현하지 않습니다. 따라서 픽셀 단위로 완전히 동일한 글자 모양을 보장하지는 않습니다.

하단 덮개는 `MODAL_BG.PNG`, 게이지와 구분선은 `DLG_LOADING_1.PNG`의 `CHAR_GAUGE`, `CHAR_LINE` UV를 사용합니다. 다른 잘못된 UV 항목의 영향을 받지 않도록 해당 키만 읽습니다.

## 엠블럼과 저장

요원 등급 D·C·B·A·S·SS·SSS·X의 원본 에셋을 선택하거나 **없음**으로 지울 수 있습니다. `PARTICLE_AGENT_GRADE_01`부터 `_08`의 텍스처·크기와 컨트롤의 0.5 배율을 읽습니다. 기준 중심은 (40, 679)이며 D~A는 64×64, S~X는 128×128입니다. S~X의 20개 텍스처 프레임과 각 0.06초 표시 시간은 미리보기와 애니메이션 저장에 적용합니다. PNG는 현재 시점의 정지 이미지로 저장합니다.

캐릭터 정보를 포함한 조합은 JSON 버전 7입니다. 비표시 상태에서도 편집 내용을 복원할 수 있도록 정보 영역의 출처·해시·UV·글꼴·재생 시간을 유지합니다. 이전 조합도 불러올 수 있습니다. 프레임 템플릿에는 캐릭터 정보를 저장하지 않으며, 템플릿을 추가할 때 현재 조합의 캐릭터 정보를 유지합니다.
