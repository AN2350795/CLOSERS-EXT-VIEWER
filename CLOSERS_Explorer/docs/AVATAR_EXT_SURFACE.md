# EXT B 표면 가산 수동 비교

2026-10-31. 원본 아바타 텍스처 바인딩 경로와 공용 B 계수 상태를 확인하고 B 항의 수동 비교를 추가했다. **게임에서 현재 사용하는 계수나 장면별 활성 상태를 자동으로 가져오지는 않는다.**

## 사용법

조명 · 발광에서 아바타·조명을 선택하고 **원본 툰 음영**을 켠다. **EXT B 표면 가산 · 수동 비교**를 펼쳐 비교 계수를 직접 입력하고 비교를 켠다. 기본은 꺼짐·계수 미입력이며, 값이 없으면 적용을 보류한다. 계수 0은 가산량 0이다. 0~4는 뷰어의 비교 입력 범위이며 게임의 제한값을 뜻하지 않는다. 설정과 입력값을 저장한다.

EXT·툰 텍스처가 준비된 표면만 적용한다. R 채널 전역 반사와 독립적으로 켤 수 있으며 반사 수치가 없는 의상 조명에서도 비교할 수 있다. 얼굴 SDF는 별도 셰이더 경로이므로 이번 B 비교에서 제외한다. 조명·하이퍼 모드 효과를 자동으로 켜지 않는다. 끄면 이전 픽셀로 복원한다.

## 식과 합성 순서

최신 `CW_CARTOONLIGHT.PS.CSO`의 `mul r1.w, r5.y, cb5[18].x` / `mad r2.xyz, r0.xyzx, r1.wwww, r2.xyzx`는 EXT B와 재질 상수의 곱으로 표면색을 더한다. 기존 HLSL의 계수 없는 B 항만 참고하지 않고 최신 컴파일 결과를 따른다.

```
B 가산 = 표면색.rgb × EXT.b × 입력 계수
```

B는 파란색 가산이 아니다. R/G/alpha는 이 항에 쓰지 않는다. B 항에 툰 색·툰 밝기·조명 색·조명 강도·거리 혼합을 다시 곱하지 않는다. 기존 MatCap·반사를 포함하는 표면을 기준으로 계산하며, 원래 툰·EXT R·테두리광·GLOW·SecondMap 합성과 독립적으로 더한다. 재질 발광은 이후 별도로 더한다. alpha, 발광 전용 패스와 번짐 광원에는 영향을 주지 않는다.

## 아바타의 렌더 상태 근거

CW.EXE SHA-256 `8ea0ce3ba885f3044103c8e071e627b52a0e93cf56cc44b0e03dffed7c440283`에 한정한다.

- `0x14160554f`는 렌더러 EXT 사용 상태 +0x160을 **1**로 초기화한다. `0x141605935`의 생성과 `0x14160593b`의 전역 저장은 `0x1415fc630`에서 조회하는 같은 전역 포인터를 사용한다. 다른 객체 생성자의 같은 오프셋과 혼동하지 않는다.
- 아바타 경로 `0x141749a5b`는 `0x141712b70`을 호출한다. `0x141712bbb`에서 렌더러 +0x160이 1이면 원래 리소스 +0x118을, 아니면 렌더러 대체 리소스 경로를 선택하여 `g_tSpecularMap`에 바인딩한다. 대체 텍스처의 실제 픽셀색은 이번에 확정하지 않았다.
- B 계수 주소 `0x142f9ab00`은 PE의 `.data` 파일 데이터 뒤 가상 영역에 있어 **실행 시 초기 메모리는 0**이다. 이는 게임 실행 후 현재 값이 항상 0이라는 뜻이 아니다. 그 주소를 파일 오프셋으로 읽으면 다른 영역의 바이트를 오인할 수 있어 별도의 zero-fill 검사를 추가했다.
- 지역 오브젝트는 앞서 확인한 두 경로에서 이 공용 계수를 기록한다. `0x14167c1c9~0x14167c1ce`의 복원은 EXT 사용 플래그를 복원하며 B 계수를 복원하는 명령은 아니다. `0x1416002b0`의 직접 상수 초기화에서도 B 계수를 직접 초기화하는 쓰기는 찾지 못했다. 장면 호출 순서와 다른 간접 갱신을 확정하지 않았으므로 코스튬에 고정 계수를 연결하지 않는다.

정적 감사 도구 `tests/audit_ext_binding.py`를 **20개 검사**로 확장했다. 보고서는 `diagnostics/ext-avatar-state-20261031.json`이며 배경 입력과 아바타 경로의 확인 범위·미확정 실시간 값을 따로 기록한다. 게임과 Lua는 실행하지 않았다.

## 검증과 남은 작업

신규 브라우저 검사 2개는 독립 수치식으로 일반·4·5가중치 모델의 B=0/64/128/255, 계수 0/0.25/1/4, R/G/alpha 독립성, 툰·조명 배율과의 분리, 발광·번짐 제외, OFF 복원을 확인한다. 설정 복원, 계수 누락·오류, 텍스처 누락·늦은 로딩, 툰 OFF, 모델 지우기도 검사한다.

원본 브라우저 검사 1개는 B가 0인 기본 헤어 3종과 B가 있는 LANCER 기본 헤어·CASTER 가슴 장식·STRIKER 입 장식을 4방향에서 확인한다. 계수 1은 **진단용 수동 입력**이다. B=0 맵은 변화가 없고 B 유효 맵은 표면 가산이 생기며 계수 0에서 정확히 복원된다. 캡처는 `diagnostics/ext-surface-20261031`에 저장했다. 전체 코스튬·인게임 일치 증거가 아니다.
