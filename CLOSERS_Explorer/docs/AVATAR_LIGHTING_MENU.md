# 재질·화면 효과와 뷰어 조명 메뉴

조명은 3D 뷰어 왼쪽 위 메시지 아래의 둥근 태양 버튼에서 조작한다. 메시지가 여러 줄이면 그 높이에 맞춰 버튼 위치도 조정된다. 기존 조명·재질 버튼은 **재질 · 화면 효과**로 이름을 바꾸고 광택·발광·후처리를 담당한다. 메뉴를 열고 닫는 것만으로 조명이나 저장값을 바꾸지 않는다.

## 뷰어 안의 기본 조명

둥근 태양 버튼을 누르면 상태·직접 조명 켜짐·광원 선택을 위에 두고 **빛·배치·표시** 탭으로 나눈 메뉴가 펼쳐진다. 선택과 실제 주광원 적용을 구분하고 **선택 조명 적용**을 별도로 제공한다. 빛 탭은 색상·강도 슬라이더, 배치 탭은 빠른 방향·카메라 쪽 배치와 3D 이동·되돌리기, 표시 탭은 편집 표시만 숨기는 기능이다. 종류·추가·삭제는 빛 탭의 접힌 관리 항목에 있다.

닫기 또는 같은 버튼으로 언제든 닫고 다시 열 수 있으며 모델이 없거나 전체 화면에서도 사용할 수 있다. 작은 뷰어에서는 캔버스에 메뉴가 잘리지 않도록 화면의 여유 공간을 사용한다. 내용만 스크롤하고 닫기·원본 조명·상세 설정은 유지한다.

3D 이동 시 광원 중심은 태양, 조준점은 과녁 아이콘으로 구분한다. 빨강 X·초록 Y·파랑 Z 화살표는 축 이동, 작은 색 사각형은 XY/YZ/XZ 평면 이동, 가운데 흰 손잡이는 화면 평면 이동이다. 위치/조준점과 자유 이동 또는 1·5·10 단위 간격을 선택한다. 화면 밖 광원은 **모델 옆으로**로 가져오고 Esc로 이동을 취소한다.

**아이콘·선·조절기 숨기기**는 빛을 유지하면서 표시만 모두 숨긴다. 기본 메뉴 닫기와도 별개이며 표시 숨김을 해제하면 기존 편집·선 표시 설정으로 돌아간다. **이동 끝내기**는 조절기만 숨긴다.

## 조명 상세 설정

기본 조명 메뉴의 **상세 설정**은 **광원 수치·원본 음영·조건·합성** 탭으로 나눈 창이다. 이름·음영 방식·주광원·XYZ·거리·각도, 원본 툰·얼굴·프로필, 착용 조건·지역 합성·거리·방향을 목적별로 구분한다. **원본 조명** 버튼은 원본 음영 탭으로 바로 들어간다. 원래 컨트롤과 저장값을 유지하며 탭·닫기는 내용 스크롤과 별도로 고정한다. 전체 초기화는 접힌 항목 안에 둔다.

음영 방식의 기본은 **원본 툰·얼굴 음영**이다. 지정한 주광원 1개가 원본 텍스처와 얼굴 SDF를 제어하고 일반 입체 음영을 중복해서 곱하지 않는다. 4개 광원 합산은 **일반 입체 음영 · 비교용**에서 선택한다. 원본 데이터가 없는 부위는 기존 재질을 유지한다. 실제 인게임 전체 화면과의 일치는 미검증이며 자세한 동작은 [VIEWER_LIGHT.md](VIEWER_LIGHT.md)를 참조한다.

## 재질 · 화면 효과

| 탭 | 주요 기능 |
| --- | --- |
| 기본 꾸미기 | 광택·강도, 발광·빛 번짐 |
| 화면 효과 | 색상 조절, 또렷하게, 초점 밖 흐림 |
| 고급 설정 | 추가 표면 효과, 하이퍼 색상, 광택 마스크·발광 진단 |

빛 번짐 방식과 부위별 발광은 발광 세부 설정, 광택 텍스처·마스크·반사는 광택 세부 설정에 있다. GLOW·EXT·테두리광 등 표면 효과는 고급 설정에 남긴다.

**화면 효과 사용**을 켜면 원본 형식의 색상 계산도 바뀐다. 색상 조절·또렷하게·초점 밖 흐림을 각각 선택할 수 있다. 초점 밖 흐림은 **현재 모델에 초점 맞추기**로 거리를 지정한다.

선택한 화면 효과·고급 효과·진단은 상단의 **추가 설정 N개 선택됨**과 이동 목록에 표시한다. 사용 조건이 부족해 대기 중인 선택도 포함한다. **추가 설정 모두 끄기**는 이 메뉴의 화면·재질 효과와 진단만 끄며 조명 메뉴로 옮긴 원본 음영·지역 합성·카메라 거리·광원 회전은 유지한다. 각 입력 수치도 보존한다.

## 검증

기존 메뉴 검사는 분류·저장값·효과 해제·키보드·포커스와 스크롤을 확인한다. 뷰어 조명 메뉴 검사는 기본/상세/재질 분리, 닫아도 조명 유지, 표시만 숨김, 원본 목록 로딩과 아이콘 GPU 렌더링을 확인한다. 320px 모바일부터 1920px 데스크톱까지 8개 화면 크기에서 가로 넘침과 닫기 버튼 고정을 검사하며, 실제 모델링 페이지의 전체 화면 뷰어에서 상세 창 열기/닫기도 확인한다.
