## 기본 화면

음영·광택·발광을 한 화면에 모았다. 각 카드에는 켜기와 주로 사용하는 강도, 짧은 용도 설명과 상태만 먼저 표시한다. 얼굴 음영·자동 조명 선택·광택 마스크·반사·번짐 방식·부위별 목록과 기술 설명은 세부 설정으로 접어 둔다. 지원하지 않는 모델은 조작을 감추고 이유를 표시한다.

2026-11-05 추가: 상단의 **뷰어 조명**에서 최대 4개의 광원을 추가·삭제하고 편집할 광원을 선택한다. 전체 켜짐과 개별 켜짐을 구분하며 종류·이름·XYZ 위치·조준점·색상·강도는 접힌 세부 설정에 있다. 주변 밝기는 모든 광원의 공통값이다. 기본값은 전체 꺼짐이며 기존 단일 광원 저장값도 이어받는다. 상세 동작과 확장 지점은 [VIEWER_LIGHT.md](VIEWER_LIGHT.md)를 참조한다.

빛 번짐의 5단계 비교는 **기본 꾸미기 → 발광 세부 설정 → 번짐 방식**에 있다. 광택이 적용되지 않으면 **광택 세부 설정**에서 텍스처·마스크와 부위별 상태를 확인한다.

## 화면 효과

**화면 효과 사용**은 기존 원본 형식 색상 계산 선택이다. 켜면 색상 계산도 함께 바뀐다는 안내를 바로 표시한다. 이후 색상 조절·또렷하게·초점 밖 흐림을 각각 선택한다. 초점 밖 흐림은 **현재 모델에 초점 맞추기**로 거리를 입력하고 켤 수 있다.

각 기능의 접힌 제목에 선택 여부를 표시한다. 사용 조건이 충족되지 않은 저장된 선택은 **선택됨 (사용 대기)**로 표시하며 실제 렌더 상태와 구분한다. 기술 설명은 기능 안의 자세한 설명에서 확인한다.

## 추가 설정 확인과 해제

선택된 화면 효과·고급 효과·진단이 있으면 상단에 **추가 설정 N개 선택됨**을 표시한다. **선택된 설정 보기**로 목록을 열고, 이름을 누르면 해당 탭과 접힌 설정을 펼친다. 비활성화된 선택도 이 목록에서 찾을 수 있다. 하이퍼 색상에는 파란빛이 나타날 때 끄라는 설명을 붙였다.

**추가 설정 모두 끄기**는 화면 효과 사용·색상 조절·선명도·심도, 하이퍼 색상·거리 연동·광원 회전·표면색 가산, GLOW·EXT·테두리광, 광택 범위 진단·발광 전용 표시·지역 조명 합성을 끈다. 기본 음영·광택·발광과 각 효과의 입력 수치·거리 기준은 유지한다. 이 버튼을 직접 누르기 전에는 저장된 선택을 바꾸지 않는다.

## 조작과 검증

제목·오른쪽 위 닫기 버튼·탭은 고정하고 내용만 스크롤한다. 탭은 방향키와 Home/End로 이동하며 닫으면 열기 버튼으로 포커스가 돌아간다.

브라우저 검사에서 세 탭의 분류, 세부 설정의 기본 접힘, 설명, 저장값 복원, 선택 현황에서 이동, 일괄 끄기와 수치 보존, 키보드·포커스·중복 ID를 확인한다. 320px 모바일부터 1920px 데스크톱까지 8개 화면 크기에서 모든 상세 내용을 펼친 상태의 가로 넘침과 스크롤 중 닫기 버튼 고정도 확인한다.

이번 변경은 메뉴와 조작 방식의 정리다. 게임 상태 연결·다른 의상과 반투명 재질 검증·실제 인게임 화면 대조는 별도 남은 작업이다.
