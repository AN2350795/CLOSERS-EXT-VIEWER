# 조명·재질 메뉴

2026-11-01 메뉴를 자주 쓰는 기능 중심으로 정리했다. 기존 효과의 계산식이나 인게임 재현 범위를 확장하는 변경은 아니다.

| 탭 | 주요 기능 |
| --- | --- |
| 조명 | 음영 켜기, 조명 선택, 착용 조건으로 선택, 밝기, 지원되는 얼굴 음영 |
| 광택·발광 | 광택과 발광 켜기, 강도, 빛 번짐. 세부 설정과 부위별 목록은 펼쳐서 확인 |
| 색감·선명도 | 색상 계산 모드, 색상 보정과 선명도, 프리셋 수치 복사 |
| 고급·진단 | 착용 조건과 스킨 상태, 지역 조명 합성, 거리·방향, 수동 실험, 재질 범위와 원본 출처 |

상단 제목·닫기 버튼·탭은 고정하고 내용만 스크롤한다. 탭은 방향키와 Home/End로 이동할 수 있다. 닫으면 메뉴를 열었던 버튼으로 포커스가 돌아간다.

## 정리한 옵션

- 기존 텍스처 위에 색·방향·강도를 섞던 **원본 조명 수치 비교 (실험)**와 비교 강도를 제거했다. 저장된 이전 켜짐 상태도 적용하지 않는다. 조명 선택과 툰 음영은 유지한다.
- 부위별 목록, 출처, 지원 범위 설명과 진단 기능은 접어 둔다.
- 현재 모델에서 지원하지 않는 광택·발광 조작은 감추고 지원 상태를 표시한다. 얼굴 음영도 지원되는 경우에만 조작을 표시한다.

## 수동 실험 확인과 해제

저장된 하이퍼 모드 색상, 카메라 거리 연동, 툰 광원 회전, EXT B 가산 실험 중 켜진 항목이 있으면 상단에 개수를 표시한다. **설정 보기**로 고급 탭을 연다.

**수동 실험 한 번에 끄기**는 위 네 기능을 끈다. 각 기능의 입력 수치·거리 기준값과 기본 조명·광택·발광 설정은 보존한다. 파란빛을 만드는 하이퍼 모드 색상 실험도 여기서 끌 수 있다.

## 검증과 남은 범위

새 메뉴의 탭 전환·키보드 이동·닫기 후 포커스·중복 ID·저장 설정 복원·실험 일괄 해제를 브라우저에서 검사했다. 320px 모바일부터 1920px 데스크톱까지 8가지 화면 크기에서 모든 탭의 가로 넘침과 스크롤 중 닫기 버튼 고정을 검사했다.

게임 Glow/HDR 번짐과 DOF, 실제 게임의 조명·카메라·상태값 연결, 의상별 인게임 화면 대조는 별도 남은 작업이다. 이 메뉴 정리를 인게임 화면 일치 검증으로 간주하지 않는다.
