# 카메라 거리와 조명 강도 혼합

2026-10-31. 카메라와 아바타의 월드 원점 사이 거리에 따라 원거리·근거리 조명 강도를 혼합한다. **거리 기준은 사용자가 지정하는 뷰어 설정**이다. 게임의 거리 변환식·임계값과 인게임 외형 일치는 아직 확인하지 않았다.

## 사용 방법

1. 아바타와 조명을 선택하고 **원본 툰 음영**을 켠다.
2. **카메라 거리 연동 · 뷰어 기준 지정**을 펼친다.
3. 확대해서 **현재 거리를 근거리로 등록**, 축소해서 **현재 거리를 원거리로 등록**을 누른다. 숫자로 직접 입력할 수도 있다. 원거리는 근거리보다 커야 한다.
4. **지정한 거리로 조명 강도 자동 혼합**을 켠다. 확대·축소하면 두 강도 사이를 자동으로 이동한다.

기본값은 꺼짐이며 임의의 거리 기준은 제공하지 않는다. 기준은 캐릭터별로 브라우저에 저장한다. 같은 캐릭터의 다른 의상에도 같은 기준을 사용한다. 서로 다른 캐릭터를 섞거나 아바타가 아닌 모델에서는 연동을 보류한다. 모델을 다시 불러오면 새 카메라 거리를 측정한 후 재개한다.

두 기준이 없거나 잘못된 경우 기존 수동 혼합값을 사용한다. 연동을 꺼도 수동값이 복원된다. 원본 근거리 강도가 없는 조명은 원거리 강도를 유지하고, 근거리 값 0은 정상적인 값으로 적용한다. 조명·툰·하이퍼 모드 효과를 자동으로 켜지 않는다.

## 적용식과 범위

뷰어 혼합 비율은 `clamp((원거리기준 - 현재거리) / (원거리기준 - 근거리기준), 0, 1)`이다. 거리 기준은 모델 크기나 원본 조명 수치에서 추측하지 않는다. 아바타 원점은 바운딩 박스 중심이나 머리 위치와 다를 수 있어 카메라 회전·이동도 실제 측정 거리에 영향을 줄 수 있다.

지역·스킨 조명을 먼저 합성한 뒤 `원거리강도 × (1-비율) + 근거리강도 × 비율`을 적용한다. 툰·얼굴 SDF·GLOW의 기존 강도를 갱신한다. 반사·테두리광의 독립 계수와 발광·번짐·색상 보정은 이 비율로 바꾸지 않는다. 애니메이션 루프에서는 모델이나 재질 목록을 다시 만들지 않고, 설정을 저장하지 않는다. 상태 문구는 창이 열려 있을 때 최대 초당 10회 갱신한다.

## 원본 근거와 한계

SHA-256 `8ea0ce3ba885f3044103c8e071e627b52a0e93cf56cc44b0e03dffed7c440283`의 CW.EXE를 읽기 전용으로 확인했다. `0x1415fb2f0`은 원거리 `light+0x20`, 근거리 `light+0x24`, 별도 상태의 비율 `state+0x144`를 사용한다. 플래그 `+0xbc`가 1이고 두 강도가 다르면 위 선형식을 계산하며, 다른 경우 원거리 값을 반환한다. `0x1415fea90`에서 결과를 조명 출력 상태에 전달한다.

이 함수 자체에는 거리 입력이나 비율 제한이 없다. 게임이 그 비율을 만드는 경로와 거리 임계값은 미확정이다. 뷰어의 거리 변환식·끝값 제한·토글은 비교를 위한 별도 기능이며 게임 플래그를 가져오지 않는다. `tests/audit_light_conditions.py`의 실행 파일 지문과 바이트 근거 21곳으로 재검증한다. 게임이나 원본 에셋을 실행·수정하지 않는다.

## 검증과 다음 작업

새 브라우저 검사 3개에서 5가중치 툰과 얼굴 SDF의 실제 GPU 픽셀, GLOW, 근·중·원거리, 범위 밖 제한, 수동 복원, 저장 복원, 월드 변환, 캐릭터 전환, 모델 교체·해제를 확인했다. 실제 `model.js`의 휠 입력과 렌더 루프 연동도 검사했다. 발광만 보기·번짐의 거리 독립성과 프레임별 설정 저장·목록 재생성 방지도 확인했다. 기존 자동 조명·합성·반사 위치·색상 보정·수동 혼합 검사 9개도 재검증했다.
