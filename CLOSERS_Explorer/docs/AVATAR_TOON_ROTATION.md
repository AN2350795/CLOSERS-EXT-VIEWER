# 툰 광원 회전 비교

2026-10-31. 원본의 툰 광원 방향(DLightDir)에 적용하는 Euler 회전 경로를 확인하고, 같은 순서의 수동 각도 비교를 추가했다. **게임 실행 중의 회전값을 자동으로 가져오는 기능은 아니다.**

## 사용법

조명 · 발광에서 아바타와 조명을 선택하고 원본 툰 음영을 켠다. **툰 광원 회전 비교**를 펼쳐 X/Y/Z 각도(도)를 입력하고 **입력한 각도로 툰 광원 회전**을 켠다. 각도는 -360~360 범위를 지원한다. 기본은 꺼짐·0도이며, 켜짐과 각도를 브라우저에 저장한다. 잘못된 입력은 마지막 유효값을 유지한다. 회전 0도로 초기화하거나 회전을 끄면 기존 방향을 사용한다.

이 설정은 조명 프로필을 바꿔도 유지하는 뷰어 비교값이다. 효과를 자동으로 켜지 않으며 하이퍼 모드 색상과도 독립적이다. 지역·스킨 조명을 합성한 경우 **지역 방향**에 회전을 적용한 뒤 거리별 강도를 혼합한다. 색·강도·원본 프로필을 수정하지 않는다.

## 원본 경로

CW.EXE SHA-256 `8ea0ce3ba885f3044103c8e071e627b52a0e93cf56cc44b0e03dffed7c440283`을 읽기 전용으로 조사했다.

- `0x1415feb74~0x1415fec07`: LightParam+4/+8/+12의 위치를 정규화하고, +0x60/+0x64/+0x68의 X/Y/Z 각도에 `0x142423774`의 약 π/180을 곱한다.
- `0x141562ed0`: 각도를 1/2로 줄여 sin/cos와 상수 셔플·부호로 쿼터니언을 구성한 뒤 회전 행렬을 만든다.
- `0x1415fec0c~0x1415feca4`: 정규화한 위치 벡터를 행렬로 회전하고 다시 정규화하여 CBPerLight+0xa0(`0x142f9ac80`)의 DLightDir에 기록한다.

절반 각도의 sin을 sx/sy/sz, cos를 cx/cy/cz라 하면 쿼터니언은 다음과 같다. 원본 상수 셔플 `0x1425b3c20~0x1425b3c4f`와 부호 `0x1425b3c10`에서 식을 확인했다.

```
x = sx*cy*cz + cx*sy*sz
y = cx*sy*cz - sx*cy*sz
z = cx*cy*sz - sx*sy*cz
w = cx*cy*cz + sx*sy*sz
```

이는 `qY*qX*qZ`, 벡터에는 **Z → X → Y** 순서다. 뷰어에서는 원본 좌표에서 회전한 후 기존 Z축 반전을 적용한다. 뷰어 좌표로 뒤집은 벡터에 같은 각도를 먼저 적용하지 않는다.

일반 LightDir은 별도의 `normalize(-LightPos)`이며 이 회전을 사용하지 않는다. EXT·테두리광은 일반 방향을 유지하고 위치 기반 반사는 LightPos를 유지한다. 얼굴 SDF도 별도 방향 입력을 유지한다. GLOW·발광·번짐·색상 보정에는 이 회전을 곱하지 않는다. 게임의 장면별 각도 선택·갱신 경로, 얼굴 전용 광원과의 관계, 전체 외형 일치는 추가 확인이 필요하다.

## 검증과 남은 작업

합성 브라우저 검사 2개에서 독립적인 축별 sin/cos 계산과 GPU 툰 램프 픽셀을 대조한다. 일반·4·5가중치 모델에서 단일 축과 복합 회전, Z 반전 순서, alpha 유지, OFF 복원을 확인한다. 설정 저장·복원, 잘못된 입력, 초기화, 조명 변경, 늦은 텍스처 로딩, 지역 합성 후 방향 선택과 카메라 거리 혼합의 동시 적용도 검사한다. 일반 방향·위치와 얼굴 방향이 보존되는지 확인한다.

원본 헤어 3종(세하·슬비·유리)과 지역 조명 2종에서 지정한 각도가 툰 픽셀을 바꾸고 OFF 시 정확히 복원되는지 확인한다. 캡처는 `diagnostics/toon-rotation-20261031`에 저장한다. 이 각도는 **진단용 입력**이며 게임의 실제 회전값이나 전체 의상·인게임 화면 일치 증거가 아니다.

기존 거리 연동·지역 합성·툰·얼굴·EXT·테두리광·반사 위치 검사 11개를 재검증한다. 실행 파일 근거는 `tests/audit_light_conditions.py`의 지문 고정 바이트 검사 30곳으로 확인한다. 보고서는 `diagnostics/toon-rotation-20261031.json`에 보관한다.

다음은 EXT 텍스처 B 채널의 원본 사용 경로와 적용 계수를 확인하는 작업이다. 게임의 실제 회전 상태와 거리→비율 경로, 지역·스킨 선택 상태의 자동 연결, 장면별 후처리 및 인게임 대조도 남아 있다.
