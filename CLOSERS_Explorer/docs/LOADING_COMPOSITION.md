# 로딩 이미지 조합의 게임 데이터

현재 던전 로딩 화면을 기준으로 사용한다. 원본 텍스처 전체 크기나 캐릭터 정보 화면의 미리보기 크기를 출력 크기로 사용하지 않는다.

| 기능 | 원본 데이터와 적용 규칙 |
|---|---|
| 일러스트 목록 | `ILLUST_TEMPLET.NTF`에 등록된 ID·캐릭터와 `ILLUST_CONVERT_DATA.NTF`의 유형 3을 연결한다. 유형 1(HUD), 2(정보 배경), 4(스킬 컷인), 5(Spine 리소스)는 제외한다. 단순 파일명 접두어 검색을 사용하지 않는다. |
| 한국어 이름 | 일러스트의 `ST_SKIN_NAME_*`, 프레임의 `ST_FRAME_NAME_*`를 한국어 기본·UI·아이템 문자열 테이블에서 조회한다. 문자열 내부 암호화도 복원하고 표시용 색상 코드는 제거한다. 이름이 없을 때만 원본 식별자를 표시한다. |
| 일러스트 영역 | 해당 텍스처의 TET에서 `LOADING_DUNGEON` UV를 사용한다. 썸네일과 실제 합성에 같은 자르기 영역을 사용한다. 일부 TET는 원본 경계를 1픽셀 넘으므로 등록 일러스트에 한해 이를 보존한다. |
| 출력 크기 | `DLG_LOADING_DUNGEON_START_V2.LUA`의 `SLOT_1_INFO` 안 `LOADING_DUNGEON` 그림 크기를 사용한다. 현재 로컬 데이터는 450×640이다. |
| 프레임 | 같은 컨트롤의 TOP·BOT 좌표를 일러스트 원점 기준으로 변환한다. 현재 TOP=(0,0,450,170), BOT=(0,556,450,84)이다. |
| 마크 위치 | 같은 로딩 컨트롤에서 해당 마크 텍스처·UV를 사용하는 그림이 있을 때만 그 위치와 크기를 적용한다. 없으면 위치 데이터가 없음을 표시하고 교체 전 위치를 유지한다. 다른 화면의 마크/파티클 좌표를 던전 로딩 좌표로 사용하지 않는다. |

슬롯 전체 크기는 454×724이며, 그 안에는 일러스트 외에 진행률 표시 영역 등이 있다. 조합의 출력 대상은 이 전체 슬롯이 아니라 일러스트 그림의 450×640 영역이다. 원본 PNG가 1024×1024여도 출력은 게임 표시 영역 크기를 따른다. 기존 조합 설정을 불러올 때도 레이어의 상대 배치를 새 출력 크기에 맞춘다.

로컬 클라이언트의 던전 로딩 UI에는 별도 마크 그림이 등록되어 있지 않다. 실행 파일의 로딩 화면 구성 경로(`0x14095daf0` 함수)에서도 슬롯 그림의 TOP·BOT와 프레임 효과를 구성하는 것을 확인했다. 프레임 테이블의 `m_PVPMatchingImg` 계열 마크와 다른 화면용 효과 위치를 현재 일러스트의 좌표라고 가정하지 않는다. 주소는 조사한 실행 파일에만 해당하며 제품 코드에 하드코딩하지 않는다.

예: `ST_FRAME_NAME_67`은 **알로하 아일랜드**이며, `ST_SKIN_NAME_100`은 **4월의 고양이**이다. 실제 원본 CMF를 읽어 등록 목록·이름·자르기·출력을 검증한다. 게임 계정의 보유 여부나 현재 활성화된 콘텐츠 버전을 판정하는 기능은 포함하지 않는다.

프레임 목록의 **게임 효과** 표시는 게임 데이터에 효과가 등록되어 있다는 뜻이다. `PARTICLE_SYSTEM_UI.LUA`, `_2`, `_3`와 `TEX_ANIM_DATA.LUA`에서 연결된 평면 파티클을 읽고, 프레임과 별도 마크 효과 모두 같은 재생기로 미리보기·PNG·APNG에 그린다. 프레임·마크 선택 시 자동 재생한다. 현재 로컬 등록 데이터에서 사용하는 81종의 효과 정의를 처리하며, 새 데이터의 알 수 없는 이벤트나 누락된 에셋은 선택 후 경고로 표시한다. APNG 저장 시 실제 출력 픽셀을 비교하며, 저장 구간 전체가 동일하면 파일을 내려받지 않고 안내한다. 효과 시작 지연보다 저장 길이가 짧거나 효과가 가려진 경우도 같은 검사를 적용한다.

| 파티클 규칙 | 적용 |
|---|---|
| 방출과 수명 | 즉시 방출, 초당 방출 범위, 동시 입자 제한, 방출 반경, 최소 반경, 방출 종료 시간·사망 개수, 입자별 수명 |
| 시간별 이벤트 | `PCET_INITIAL`, `PCET_FADE`, `PCET_FADE_FINAL`의 값과 시간. FINAL의 끝점은 해당 입자의 수명이다. |
| 변화 항목 | 색상·이중 블렌딩 색상·깜빡임·크기·배율·좌표·속도·회전·회전 속도·UV 이동. 속도와 회전 속도는 시간에 대해 적분한다. |
| 텍스처 | 프레임별 시간, 입자별 재생 시점, UV 반복·클램프, 별도 고정 UV 마스크. 마스크의 RGB와 알파를 모두 반영한다. |
| 합성 | 원본 SRC/DST 인자의 ZERO, ONE, SRCALPHA, INVSRCALPHA, DESTALPHA, INVSRCCOLOR와 이중 패스. 반복 그리기 횟수는 클라이언트처럼 정수로 읽는다. |
| 재현과 저장 | 효과 이름으로 만든 고정 난수 시드를 조합 JSON 버전 3에 저장한다. 뒤로 탐색하거나 다시 불러와도 같은 시점의 입자가 같으며, 사라진 입자 이력은 메모리에 누적하지 않는다. 기존 버전 1·2 설정도 읽는다. |

별도 마크는 이 로딩 UI에 등록된 배치가 없으므로 다른 화면용 좌표를 가져오지 않는다. 별도 효과를 마크 중심에 붙이고, 마크의 이동·크기·불투명도·숨김을 따라가게 한다. 조각 복제·삭제와 설정 복원도 이 연결을 유지한다. 이 중심 배치는 게임의 던전 로딩 기본 좌표라고 표시하지 않는다.

실행 파일의 파티클 경로도 정적으로 대조했다. 조사한 `CW.EXE`의 `0x1415b9f87` 부근에서 이중 패스의 SRCALPHA/DESTALPHA 설정, `0x1415b6e73` 부근에서 정수 그리기 횟수, `0x1415c0dee` 부근에서 최소 반경을 방향 벡터에 더하는 동작을 확인했다. 최소 반경은 XYZ가 아닌 수치 범위로 읽으며, 일부 원본 테이블에 있는 세 번째 값은 사용하지 않는다. 주소는 조사한 바이너리에만 해당한다.

난수 시드는 게임 프로세스의 난수 상태와 공유하지 않는다. 정의에 따른 동작을 재생하는 것이며 실제 게임 플레이 화면과 픽셀 단위로 대조한 결과는 아니다. 투명 배경의 가산 효과는 검은 사각형이 남지 않도록 색상 기여도를 유지하며 알파를 구성한다. GPU 텍스처 캐시는 64 MiB로 제한하고 조합에서 제거한 원본은 캐시에서도 해제한다.

애니메이션 저장의 기본 형식은 **무손실 WebP**이며 APNG도 선택할 수 있다. 두 형식은 동일한 렌더링 결과를 사용한다. WebP는 로컬 서버의 Pillow/libwebp로 각 프레임을 무손실 VP8L로 인코딩하고, WebP ANMF에 전체 화면 크기·이전 화면 교체·투명 배경으로 정리 플래그를 기록한다. 동일한 프레임도 합치지 않으므로 샘플 수를 유지한다. 60 FPS처럼 밀리초로 나누어떨어지지 않는 시간은 누적 시각을 반올림해 전체 길이를 보존한다. 투명 배경을 끄면 지정한 배경 위에 합성한 결과를 저장한다. 투명 배경 자체의 RGBA가 같아도 뷰어가 그 뒤에 표시하는 배경색은 다를 수 있다.

WebP 변환은 인증된 로컬 바이너리 요청만 받으며 입력·출력 각 128 MiB, 최대 250프레임, 프레임당 16,777,216픽셀·전체 134,217,728픽셀로 제한한다. 한 번에 하나씩 인코딩하며 디코딩한 프레임 전체를 메모리에 누적하지 않는다. 원본 CMF나 추출 파일은 변경하지 않는다. APNG의 기존 한도는 유지한다.

저장 완료 시 형식·프레임 수·FPS·길이를 표시하고, 다운로드한 것과 동일한 Blob을 브라우저 미리보기로 재생한다. 기본값 3초·25 FPS는 75프레임이다. 미리보기를 닫으면 이미지 URL을 해제한다. 외부 뷰어에서 프레임 수나 재생이 다르게 보이는 경우 이 미리보기와 비교할 수 있다.
