# 장비 메시 표시 규칙

## 적용 범위

`names` 명령으로 이름 인덱스를 생성할 때 `ITEM_MODEL_TEMPLET*.NTF`의 표시 규칙과 `FRAME_UNIQUE_ID.LUA`의 메시 그룹 목록도 함께 저장한다. 게임 스크립트를 실행하지 않고, 지원하는 Lua 5.1 바이트코드의 초기 정적 테이블만 읽는다. 키와 원본 게임 파일은 저장소에 포함하지 않는다.

로컬 클라이언트에서 확인한 규칙은 다음과 같다.

- 모델 테이블의 0부터 세는 33번 열은 메시 그룹 표시 우선순위다.
- 34번 열은 쉼표로 구분한 메시 그룹 번호다.
- 장착한 모델들이 지정한 그룹별 최대 우선순위를 계산한다.
- 메시가 속한 그룹의 최대 우선순위보다 해당 모델의 우선순위가 낮으면 그 메시를 숨긴다. 같은 우선순위는 유지한다.
- 메시 그룹은 원래 프레임 이름에 대해 Lua 목록 순서로 접두어를 비교한다. `EQ_LEG2`와 `WSM_EQ_LEG2`는 그룹 2이며, `EQ_LEG`와 `WSM_EQ_LEG`는 그룹 1이다. 목록 순서를 보존해야 숫자가 붙은 이름을 그룹 1로 잘못 분류하지 않는다.

이는 모든 다리 메시를 제거하거나 나중에 선택한 장비를 무조건 우선하는 규칙이 아니다. 메시와 원본 파일을 보존하고 API의 `equipment_hidden` 속성으로 가시성만 전달한다. 본 화면과 목록 미리보기가 같은 규칙을 사용하며, **장비 숨김 해제**로 원래 메시를 다시 표시할 수 있다.

## 다른 장비 부위 전체를 가리는 아바타

모델 테이블의 0부터 세는 26~32번 열에는 `EP_AVATAR_DEFENCE_UPBODY` 같은 장비 부위 참조가 최대 7개 들어 있다. 로컬 클라이언트의 `0x1411a29f2` 부근에서도 이 7개 열을 순회하며 부위 식별자를 읽는다. 그룹 우선순위인 33~34번 열과는 별개다.

티나 늑대개 특수대원 슈트 `300818518_GUST_USER_ARMS_PROMOTION_03_EP_AVATAR_ONE_PIECE.X`의 세 아이템 행은 모두 상의·하의·신발·장갑을 지정한다. 이 슈트의 그룹 우선순위는 0이고 그룹 목록은 비어 있으므로 기존 그룹 비교만으로는 함께 선택한 다른 부위를 숨길 수 없었다.

이 부위 참조를 `model_part_overrides`에 별도로 저장하고, 같은 캐릭터의 지정된 다른 부위 전체를 숨김 처리한다. 지정 부위의 BASE·ALPHA·DYE 모두 대상이며 머리·얼굴 등 지정하지 않은 부위는 유지한다. 장착 순서에 의존하지 않고, 원본 파일·메시를 삭제하거나 화면 위에 강제로 덧그리지 않는다. 슈트를 제거하면 다른 부위가 다시 표시되며 **장비 숨김 해제**로 원래 형상을 비교할 수 있다.

자기 부위 참조가 있어도 같은 아이템의 BASE·ALPHA·DYE를 서로 숨기지 않는다. 이미 다른 장비에 가려진 모델의 부위 참조·그룹 우선순위는 후속 숨김에 참여하지 않는다. 서로 가리는 순환 관계에 우승자를 정할 근거가 없으면 해당 형상을 보존한다. 같은 X 파일의 아이템 행들 사이에 부위 목록이 다르면 그 파일의 부위 규칙도 보류한다. 기존 그룹 규칙의 모호성 여부와는 독립적으로 판단한다.

이름 인덱스 후처리에 포함되므로 새 환경에서도 게임 테이블에서 자동 생성된다. 이전 인덱스는 후처리를 다시 실행하면 추가된다. 이전 인덱스나 캐릭터·부위를 식별할 수 없는 모델에는 부위 전체 숨김을 추측해서 적용하지 않는다. 게임 실행 화면과 모든 의상의 전수 비교를 뜻하지 않는다.

## 미래 바니걸 사례

미래 `CLOTH_14_A`의 상의 301710804와 하의 301710805는 그룹 2에 우선순위 1을 지정한다. 신발 301710806은 우선순위 0이다. 따라서 상의 또는 하의와 함께 장착하면 신발 내부의 `EQ_LEG2_REAPER_FOOT_MC`를 숨기고, 일반 신발 및 그룹 1·3의 다리 메시를 유지한다. 신발만 열면 해당 메시도 다시 표시한다.

해당 상의와 신발의 그룹 2 메시 사이에는 원본 좌표·면 방향·스킨 가중치가 일치하는 면이 있다. 이 사례의 원인은 두 파일의 메시를 모두 표시하면서 원본의 그룹 우선순위를 적용하지 않은 데 있었다.

검증에 사용한 로컬 클라이언트의 정적 코드 경로:

- `0x1411a2a7e` 부근: 모델 열 33을 구조체 +0x10, 열 34를 +0x58의 번호 목록으로 읽는다.
- `0x140613b4d` 부근: 장착 모델의 번호 목록을 순회하며 그룹별 최대 우선순위를 만든다.
- `0x14174c3f8` 부근: 그룹별 우선순위가 현재 모델보다 높을 때 메시 그리기를 건너뛴다.
- `0x1416f73e0`: 프레임 이름을 정적 접두어 목록과 비교해 그룹 번호를 정한다.

주소는 조사한 설치본에 한정하며 프로그램은 이 주소에 의존하지 않는다.

## 헤어 눈썹 우선 표시

같은 캐릭터의 헤어와 얼굴에 `EQ_EYEBROW` 또는 `WSM_EQ_EYEBROW` 프레임이 함께 있으면 헤어의 눈썹을 표시하고 얼굴의 눈썹을 숨긴다. 눈썹이 헤어 본체 메시와 합쳐진 모델은 얼굴 눈썹 전용 뼈에 연결된 헤어 정점으로도 판별한다. 전용 뼈는 선택한 얼굴의 눈썹 메시에서 수집하고, 눈·피부 등 다른 얼굴 메시에서도 사용하는 뼈는 제외한다. 실제 삼각형이 참조하는 정점의 양수 스킨 가중치만 사용하며 특정 캐릭터의 뼈 이름을 하드코딩하지 않는다.

최신 인덱스에서는 보통 그룹 5의 우선순위로 처리된다. 하지만 `J's Volume Straight Perm`의 `300300302_GUST_USER_FIGHTER_ALPHA_A_EP_AVATAR_DEFENCE_HAIR.X`는 눈썹이 본체 메시 안에 있고, 같은 X 파일의 모델 행들에 그룹 5·우선순위 1과 그룹 없음·우선순위 0이 섞여 있다. 따라서 인덱스는 이 파일의 규칙을 보류한다. 이때도 얼굴 눈썹 전용 뼈와 연결된 헤어 형상을 확인해 베이스 눈썹만 숨긴다. 인덱스가 없는 경우에도 동일하게 처리한다.

헤어에 이름으로 확인한 눈썹 메시도, 얼굴 눈썹 전용 뼈에 연결된 형상도 없으면 이 보완 규칙으로 얼굴 눈썹을 숨기지 않는다. 헤어 액세서리와 다른 캐릭터의 헤어, 이미 숨겨진 헤어는 대체 대상으로 사용하지 않는다. 다른 메시와 원본 형상·텍스처는 보존하며 기존 **장비 숨김 해제**로 숨긴 눈썹도 다시 확인할 수 있다.

## 보수적으로 유지하는 경우

- 기존 이름 인덱스에 표시 규칙이나 프레임 목록이 없으면 그룹 우선순위는 적용하지 않는다. `names` 명령으로 다시 생성하면 함께 반영된다. 위의 헤어 눈썹 보완 규칙은 인덱스 없이도 적용한다.
- 원본 CMF가 바뀌어 인덱스가 무효화되면 표시 규칙도 함께 사용을 중단한다.
- 같은 X 파일을 참조하는 아이템들의 표시 규칙이 서로 다르면, 현재 선택된 아이템 번호를 알 수 없으므로 해당 파일의 규칙을 자동으로 고르지 않는다.
- 소유 모델의 우선순위를 확인할 수 없는 메시, 등록되지 않은 프레임 이름은 그룹 우선순위만으로 숨기지 않는다. 위의 헤어 눈썹 보완 규칙은 별도로 적용한다.
- BASE와 짝이 되는 DYE 파일이 인덱스에 있지만 현재 구성에 빠졌으면 그 BASE의 그룹 우선순위 적용을 보류하고 화면에 안내한다. 일부 의상은 DYE 파일이 다리나 의상 표면을 제공하므로, 누락 상태에서 다른 부위의 다리까지 숨기면 빈 공간이 커질 수 있다.
- 변신·이벤트별 프레임 제어, 25번 열의 조건부 부위 목록, 재질·셰이더 조건 등 다른 게임 표시 규칙은 포함하지 않는다. 26~32번 열의 부위 전체 숨김과 33~34번 열의 그룹 우선순위를 구분해 적용한다.

## 검증

단위·통합 테스트는 정적 Lua 파싱, 잘린 입력·실행 명령 거부, 우선순위 비교, 장착 순서 독립성, 알 수 없는 출처 보존, DYE 누락 보호, 원본 바이트 보존 및 인덱스의 생성·무효화를 검사한다. 브라우저 테스트는 API의 숨김 속성이 실제 모델 가시성에 전달되는지 확인한다.

부위 전체 숨김은 7개 열 파싱, BASE·ALPHA·DYE 전체 숨김, 자기 아이템 보존, 다른 캐릭터 제외, 장착 순서, 슈트 제거 후 복원, 숨긴 모델의 후속 영향 제외와 순환 관계 보존을 검사한다. 실제 티나 슈트와 기본 상의·하의·신발·장갑·머리·얼굴을 공용 뼈에 연결한 장면 데이터에서도 두 장착 순서 모두 다른 의상 메시 9개가 숨겨지고 슈트·머리·얼굴이 유지됐다. 슈트가 없는 구성에서는 상의·하의·장갑·신발 본체가 복원되고 기존 그룹 규칙에 따른 신발 내부 다리 메시 3개의 숨김은 유지됐다.

눈썹 회귀 테스트는 별도 눈썹 메시와 헤어 본체에 합쳐진 눈썹, 인덱스·소유 모델 규칙 누락, 장착 순서, 전용 뼈와 공유 뼈의 구분, 가중치 0·미사용 정점, 숨긴 헤어, 다른 캐릭터 및 액세서리 제외를 검사한다. 실제 `J's Volume Straight Perm` 헤어와 제이 기본 얼굴을 공용 뼈에 연결하고 원본 텍스처를 사용해 9개 각도로 수정 전후를 렌더링했다. 정면에서 베이스의 밝은 눈썹 중복이 사라지고 헤어의 갈색 눈썹이 남는 것을 확인했다. 이는 게임 실행 화면과의 비교를 뜻하지 않는다.

추가로 실제 미래 `CLOTH_14_A`, 이슬비 `CLOTH_225_A`, 제이 `CLOTH_228_A`, 이세하 `CLOTH_165_A`의 의상 메시와 원본 텍스처를 여러 각도에서 비교한다. 이슬비처럼 해당 그룹을 숨길 이유가 없는 조합은 수정 전후 픽셀이 같아야 하며, DYE를 제외한 이세하 조합에는 새 숨김이 적용되지 않아야 한다. 이는 게임 실행 화면과 모든 의상·동작을 전수 비교한 검증을 뜻하지 않는다.
