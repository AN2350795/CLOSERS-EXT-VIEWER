# 장면 화면 효과와 그래픽 옵션 프리셋의 구분

2026-11-01. 원본 색상 프리셋의 선택 범위와 함께 저장된 후처리 설정을 대조했다. **원본 프리셋의 전체 후처리를 재현하거나 장면별 프리셋을 자동 선택하는 기능은 아니다.**

## 뷰어에서 확인하는 방법

조명 · 발광 → 색상 보정 비교에서 원본 프리셋을 선택한 뒤 **선택 프리셋의 원본 구성 · 적용 범위**를 펼친다. 원본의 색상 보정·빛 번짐·심도 효과·선명도 상태와 선명도 수치를 확인할 수 있다. 선택 경로가 그래픽 옵션임을 표시하고 원본 파일과 행 번호를 함께 남긴다.

프리셋 선택만으로 수치가 바뀌지는 않는다. 적용 버튼은 기존처럼 RGB·밝기·대비·채도만 복사한다. 색상 보정 켜짐, 뷰어 발광 번짐과 다른 효과 선택은 유지한다. 직접 입력값 복원도 유지한다. 다른 후처리 수치가 손상되거나 조회되지 않으면 확인 불가로 표시하고, 유효한 색상 수치는 계속 비교할 수 있다. 프리셋 API 캐시 버전은 8이다.

## 확인한 원본 프리셋

`GRAPHIC_OPTION_DATA_DETAIL.NTF` 범주 5가 그래픽 옵션 프리셋이다. 숫자 열은 0부터 세며, 7~12가 기존 색상 수치다. 5/6은 빛 번짐/심도 효과의 활성 입력이고, 13은 선명도 수치다. 빛 번짐/심도 효과는 원본 적용 경로에서 **1과 비교**하며, 단순히 0이 아니면 켜짐으로 취급하지 않는다. 선명도는 범주 4의 범위를 확인하고 0보다 크면 활성이다.

| 프리셋 | 빛 번짐 | 심도 효과 | 선명도 |
| --- | --- | --- | --- |
| 1 | 켜짐 | 켜짐 | 1.55 |
| 2 | 켜짐 | 켜짐 | 0 (꺼짐) |
| 3 | 켜짐 | 켜짐 | 0 (꺼짐) |
| 4 | 꺼짐 | 꺼짐 | 1.5 |
| 5 | 켜짐 | 켜짐 | 0 (꺼짐) |
| 6 | 켜짐 | 꺼짐 | 1 |
| 7 | 켜짐 | 켜짐 | 0 (꺼짐) |

이 7개 모두 원본 색상 보정 활성값은 켜짐이다. 프리셋 4의 채도 0은 무채색 보정이며 비활성을 뜻하지 않는다. 표는 읽기 좋게 반올림했으며 API는 원본 float32를 유지한다. 이 표의 빛 번짐 상태와 뷰어의 발광 전용 번짐 구현은 같은 기능으로 간주하지 않는다.

## 지역 화면 효과는 별도 입력

`WORLD_TEMPLET.m_vecWorldScreenEffect`의 로더 `0x141673bf0`는 `m_TexName`, `m_UVSpeed`, 소스/대상 블렌딩, 그리기 횟수, 현재/목표 색을 읽는다. 이 목록을 그래픽 옵션의 색상 프리셋 번호로 해석할 근거는 확인되지 않았다.

현재 비교 지역 중 평화의 광장 황혼은 이 목록이 비어 있고, 몽마르트르 황혼에는 명시 리터럴 필드가 없는 항목 1개가 있다. 필드가 비어 있다는 사실을 모든 런타임 화면 효과가 꺼진다는 뜻으로 해석하지 않는다. 누락값을 중립 색상 보정이나 프리셋 0으로 대체하지 않는다. 지역·기후·시간대 이름으로 색상 프리셋을 추측하지 않는다.

CW.EXE SHA-256 `8ea0ce3ba885f3044103c8e071e627b52a0e93cf56cc44b0e03dffed7c440283`의 `0x1406cb949`는 저장 설정 `PostEffectPreset`을 +0xcc로 읽는다. `0x140092875`, `0x1400928c4`는 빛 번짐/심도 활성값을, `0x140092a78~0x140092ba8`는 선명도 수치와 활성값을 설정한다. 출력 감사 도구를 32개 근거 검사로 확장했다. 다른 시스템 설정 경로·실시간 장면 덮어쓰기는 여전히 미확정이다.

진단은 게임·Lua를 실행하지 않고 원본을 수정하지 않는다. 지역 SHA-256·아카이브·ordinal, 화면 효과의 명시 필드·누락·미확인 필드와 프리셋 출처를 기록한다. 실제 후처리를 활성화하지 않는다.

파싱·API·GPU·설정 복원을 포함한 검사 21개와 실행 파일 근거 32곳을 통과했다. 프리셋 상세 조회와 적용이 다른 효과를 바꾸지 않는지, 잘못된 비색상 수치가 색상 보정을 막지 않는지도 확인했다.

후속 단계에서 [원본 선명도 셰이더·계수 연결과 수동 비교](AVATAR_SHARPEN.md)를 구현했다. 색상 적용 버튼은 계속 색상 수치만 복사하며, 선명도는 별도 버튼으로 수치만 가져온다. 감사 근거는 42곳으로 확장했다. 이어 [Glow/HDR와 발광 전용 번짐의 범위 대조](AVATAR_BLOOM.md)를 진행했다. 원본 방식 구현에는 blur 타깃·계수·입력과 실제 모드 연결 확인이 더 필요하다. 원본 심도 효과, 장면의 실제 선택/덮어쓰기, B 공용 계수·회전·거리 상태 연결, 전체 의상과 인게임 화면 대조도 남아 있다.
