# 지역 기본 조명과 스킨 조명 합성

2026-10-31. 원본 파일과 실행 파일은 읽기만 한다. 게임을 실행하거나 원본 데이터를 수정하지 않는다.

## 확인한 원본 규칙

스킨 선택 종류 5의 템플릿에서 조명 데이터를 찾은 뒤 기존 캐릭터 조명에 일부 값만 덮어쓴다. [선택값 조회 근거](AVATAR_LIGHT_CONDITIONS.md)와 같은 실행 파일 SHA256을 기준으로 한다.

| 항목 | 캐릭터 경로 | 별도 장면 경로 |
| --- | --- | --- |
| 근거 | `0x140a6cda4`, `0x140a80818` | `0x140a9eed8` |
| RGB | 스킨 RGB 복사 | 스킨 RGB 복사 |
| 원거리 강도 | `max(기존 강도, 스킨 강도)` | 스킨 강도 복사 |
| 근거리 강도 | 스킨 근거리 강도 복사 | 스킨 근거리 강도 복사 |
| 추가 스칼라 | 스킨 값 복사 | 스킨 값 복사 |
| 색상 alpha·광원 위치·방향·반사·테두리광 | 이 복사 블록에서 덮어쓰지 않음 | 이 복사 블록에서 덮어쓰지 않음 |

캐릭터 경로는 `+0x248/+0x24c/+0x250`에 RGB를 쓰고 `+0x258`의 기존 강도와 스킨 데이터 `+0x20`을 비교한다. 근거리 `+0x25c`와 추가 스칼라 `+0x260`은 비교 없이 바꾼다. 별도 장면 경로는 `+0x760/+0x764/+0x768`, `+0x770/+0x774/+0x778`에 직접 복사한다. 따라서 모든 경로에서 원거리·근거리 둘 다 max를 쓰거나 기존 RGB와 스킨 RGB를 곱하면 원본과 다르다.

`tests/audit_light_conditions.py`의 근거를 13곳에서 **16곳**으로 늘려 RGB·원거리·근거리·추가 스칼라 복사 블록 전체를 검사한다. 알려지지 않은 실행 파일은 거절한다.

## 구현과 사용

조명 · 재질의 **지역 기본 조명**에서 평화의 광장/몽마르트르 황혼을 직접 지정한다. 기본값 **합성 안 함 · 기존 비교 유지**에서는 기존 프로필과 렌더링을 그대로 사용한다. 지역과 스킨은 별도로 선택하며, 스킨은 기존 수동 비교 또는 선택 상태·착용 조건 기능으로 결정한다.

**원거리 강도 합성**은 다음 둘 중 하나다.

- **지역·스킨 중 밝은 강도 유지**: 캐릭터 경로의 max 규칙.
- **스킨 강도로 변경**: 별도 장면 경로의 직접 복사 규칙.

합성은 `composeAvatarLight(base, skin, policy)`에서 수행한다. 지역의 위치·방향·반사·테두리광·색상 alpha를 보존하고 스킨 RGB·원거리/근거리 강도·추가 스칼라를 연결한다. 원본 객체를 변경하지 않는다. 원본 스킨 선택 경로에 연결되지 않은 다른 프로필이나 유효하지 않은 수치는 합성을 보류한다.

스킨을 선택하지 않았거나 **선택 없음 (0)**이면 지역 조명만 사용한다. 이때 지역 근거리 강도도 그대로 유지한다. 합성 자체를 끄면 기존 스킨 단독 비교로 돌아간다. 지역·방식은 설정에 저장하며 마지막 수동 조명과 효과 켜짐 상태를 바꾸지 않는다. 정의가 누락되거나 목록 조회가 실패하면 이전 합성값을 재사용하지 않고 보류한다. 다시 조회되면 설정에 맞게 복구한다.

합성 결과를 **수동 혼합 또는 사용자 기준의 카메라 거리 혼합**에 전달한다. 예를 들어 지역 원거리 1.4, 스킨 원거리 0.5/근거리 0.2일 때 max 합성은 1.4/0.2이고, 혼합 50%는 0.8이다. 직접 복사 합성은 0.5/0.2, 50%는 0.35다. 거리 혼합 뒤에 max를 적용하지 않는다. [카메라 거리 연동](AVATAR_CAMERA_LIGHT.md)은 뷰어에서 지정한 기준을 사용하며 원본 게임의 거리 임계값을 재현했다는 의미는 아니다.

툰·얼굴·GLOW와 EXT·테두리광에 합성 결과를 전달하고 MatCap의 지역 반사 광원도 지역 위치를 따른다. 발광·후처리와 기존 단순 색상 수치 비교 실험은 별도다. 추가 스칼라는 합성 메타데이터로 보존하며 아직 확인되지 않은 셰이더 효과를 새로 켜지 않는다.

## 검증과 남은 범위

새 브라우저 검사 2개는 0·4·5개 스킨 가중치의 실제 GPU 픽셀을 독립적인 수치식과 대조한다. RGB 복사·alpha 유지·원거리 max·근거리 직접 복사·거리 혼합 순서·합성 OFF의 픽셀 복원을 검사한다. UI에서는 설정 복원·선택 없음·지역 반사 위치·반사/테두리광 값 유지·목록 실패/재시도·효과 스위치 보존도 검사한다.

원본 렌더링 검사 1개는 세하·슬비·유리 기본 헤어 3종, 황혼 지역 2곳, 황천의 사자/일반 스킨 조명 2개를 조합한 12개 경우를 확인한다. 픽셀 변화와 alpha 유지, 원본 지역으로 정확히 복귀하는지 대조했다. 실제 수치에서 지역 강도가 스킨 강도보다 낮으면 max와 직접 복사 결과가 같은 것이 정상이며 이를 검사한다. 원본 데이터는 변경하지 않는다. 캡처는 `diagnostics/light-composition-20261031`에 보관한다. 전체 코스튬이나 인게임 화면 일치를 확인한 검사는 아니다.

기존 자동 선택·근거리 비교·반사 광원 위치·색상 보정 검사까지 총 **10개 테스트**와 실행 파일 근거 **16곳**을 통과했다.

지역·합성 경로는 수동으로 지정한다. 현재 지역 방향은 기존의 위치 기반 근사이며 원본 Euler 회전·캐릭터 위치·게임의 거리 변환·런타임 경로 선택은 자동 연결하지 않았다. 후속 단계에서 사용자 지정 기준의 카메라 거리 혼합을 추가했으며, 원본 선형 혼합식까지 실행 파일 근거 21곳으로 확인했다. [거리 연동 검증](AVATAR_CAMERA_LIGHT.md)을 참고한다. 다음은 원본 회전값과 광원 방향 연결을 조사하는 작업이다. 게임 상태 자동 연결, 게임 거리→비율 경로, EXT B 계수, 장면별 후처리와 인게임 화면 대조도 남아 있다.
